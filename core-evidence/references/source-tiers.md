# 来源分级与独立性

部分思路借鉴 zerox-deep-research 的信源评估（ZeroxZhang/zerox-skills），按本系统需要改写。

## 三级可信度

| 级别 | 含义 | 例子 | 能支撑什么 |
|---|---|---|---|
| A | 一手来源，或方法透明、可复核的高质量二手 | 政府和监管机构、标准原文、公司公告和年报、交易所披露、同行评审论文、附数据和方法的研究 | 关键事实与关键结论 |
| B | 可信但有局限的二手 | 行业协会、主流财经媒体的深度报道、知名研究机构报告（方法不完全透明）、券商研报 | 交叉印证、背景；可支撑非关键结论 |
| C | 可疑或明显有立场 | 自媒体、论坛、营销软文、厂商白皮书（无第三方验证）、内容农场、引用链断裂的转述 | 只当线索，不能单独支撑结论 |

判定看“事实从哪来”，不看载体：一篇博客引用了财报原文并给出页码，就这条事实而言接近一手。

## 每个来源查四项

1. 作者和机构是谁，利益立场是什么。
2. 发布日期和数据日期（见 `freshness.md`）。
3. 有没有利益冲突：厂商自评、赞助研究、广告、返佣。有冲突不等于不可信，但要在台账备注里记下。
4. 数据怎么来的：样本多大、自报还是第三方统计、是否修订过。

## 独立性

- 关键结论要么有**两个相互独立的来源**，要么有**一个 A 级一手来源**。
- 多篇文章转引同一个源头只算 1 个。判断方法：看它们引用的原始出处是否相同；不同媒体写出几乎相同的数字和措辞，多半同源。
- 同一家机构的两份材料不算独立。

## 数字口径

数字对不上时先查口径，再判断谁错：

| 项 | 要问的 |
|---|---|
| 口径 | 统计的是什么：出货量 / 销量 / 激活量 / 付费用户 / 月活 |
| 单位 | 币种、是否含税、万 / 亿 |
| 时间 | 财年还是自然年，期末值还是平均值 |
| 范围 | 集团还是子公司，全国还是部分地区 |
