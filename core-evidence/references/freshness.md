# 时效表

超过时效就算“可能过时”，要搜一下有没有更新的数据。可按行业调整，调整时在来源的 access_note 或主张的 limitation 里写明理由。

| 信息类型 | 时效 | 说明 |
|---|---|---|
| 价格、汇率、利率、大宗商品行情 | 3 个月 | 波动快的品类（芯片、锂电材料等）按 1 个月 |
| 竞争对手动态、公司人事、融资、产品发布 | 6 个月 | 重大事件（并购、退市、处罚）始终查最新 |
| 上市公司财务数据 | 最近一期披露 | 用年报 / 中报 / 季报中最新的一期，并注明期间 |
| 市场规模、份额、行业增速 | 1 到 2 年 | 高速变化的行业（AI、新能源）按 1 年 |
| 宏观数据（GDP、人口、行业产值） | 最近一次正式发布 | 注明统计口径和发布机构 |
| 政策法规、标准、认证要求 | 始终查当前有效版本 | 注意“已发布未生效”和“已废止” |
| 技术参数、产品规格 | 1 年 | 以官网或规格书为准 |
| 学术研究结论 | 看是否有更新的综述或被推翻 | 单篇研究不等于定论 |
| 方法论、经典理论 | 不过期 | 不用核实 |

## 日期怎么记

- **数据日期**：数据描述的时间（如“2025 年全年”）。
- **发布日期**：来源发布的时间。
- **访问日期**：我们打开它的时间。

三者都可能不同。判断是否过时看**数据日期**。
