# 方法卡片：平衡计分卡、战略地图与方针管理（Hoshin Kanri / OGSM）

## 它解决什么问题
把公司战略翻译成各层面、各部门可以衡量和执行的目标，并逐层分解下去。

## 怎么选
| 情况 | 用哪个 |
|---|---|
| 成熟企业，战略目标涉及多个维度，需要一套完整的衡量体系 | 平衡计分卡 + 战略地图 |
| 战略周期三到五年，少数几个突破性目标需要逐层分解到部门和个人 | 方针管理 |
| 想要一页纸讲清楚目的、目标、策略、衡量 | OGSM |
| 变化快、需要按季度调整方向 | OKR（见 OKR 卡片），可以作为平衡计分卡下面的季度执行层 |

## 什么时候不用
- 初创企业，战略还在快速试错：这些体系太重，用 OKR。

## 操作步骤（平衡计分卡）
1. 从使命和愿景出发，明确战略。
2. 在四个层面设定目标：
   - 财务：股东希望看到什么
   - 客户：客户如何看待我们
   - 内部流程：必须做好哪些流程
   - 学习与成长：需要什么能力、人才、系统
3. 画战略地图：用箭头把四个层面的目标连成因果链（学习成长 → 内部流程 → 客户 → 财务）。
4. 每个目标配上指标、目标值和行动计划。
5. 与预算和资源分配挂钩，定期回顾。

## 操作步骤（方针管理）
1. 高层确定 3 到 5 年的突破性目标和年度目标。
2. 逐层“接球”：每一层根据上一层的目标制定自己的目标和措施，并与上级反复沟通确认。
3. 用 X 矩阵把目标、策略、指标和负责人的关系画在一张图上。
4. 定期检查，用 PDCA 推进。

## 输出模板
```
| 层面 | 战略目标 | 指标 | 目标值 | 行动计划 | 负责人 |
|---|---|---|---|---|---|
| 财务 | | | | | |
| 客户 | | | | | |
| 内部流程 | | | | | |
| 学习与成长 | | | | | |
因果链：……
```

## 常见误用
- 指标太多，变成一张庞大的报表。
- 四个层面各自为政，没有因果逻辑。
- 只在年初做一次，平时不回顾。
