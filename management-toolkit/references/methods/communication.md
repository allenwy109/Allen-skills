# 方法卡片：团队沟通（乔哈里视窗、沟通反思环）

## 它解决什么问题
团队内部沟通不畅、误会多、信息不透明时，找到原因并改善。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 彼此不了解，信息不透明，有盲区 | 乔哈里视窗 |
| 经常误解对方的意思，争执不断 | 沟通反思环（推论阶梯） |

## 什么时候不用
- 问题是汇报没有条理：用 consulting-analysis 的金字塔原理。
- 问题是个人之间的冲突情绪：用 personal-effectiveness 的非暴力沟通。

## 乔哈里视窗
| | 自己知道 | 自己不知道 |
|---|---|---|
| 别人知道 | 公开区 | 盲目区 |
| 别人不知道 | 隐藏区 | 未知区 |
- 有效沟通只能在公开区进行。
- 扩大公开区的办法：主动分享信息（缩小隐藏区），主动寻求反馈（缩小盲目区）。

## 沟通反思环（推论阶梯）
人从观察到行动要经过几步：观察到的事实 → 选择性地注意部分信息 → 赋予意义 → 形成信念 → 采取行动。误解往往发生在“选择”和“赋予意义”这两步。沟通时要把推理过程说出来：“我看到……，所以我理解为……，是这样吗？”

## 资料中总结的沟通障碍和对策
- 障碍：不会倾听、认知和沟通风格差异、不考虑时间场合、缺乏换位思考、价值观差异、不恰当的肢体语言。
- 对策：暂停休息、调整心态、让情绪发泄出来、私下沟通、用幽默缓解压力；避免讨论被少数人控制，可以要求人人发言、坚持公正原则、适时提醒。

## 输出模板
```
沟通问题：……
乔哈里分析：对方不知道的 ……；我不知道的 ……
行动：主动分享 ……；主动询问 ……
```

## 常见误用
- 只要求别人透明，自己不分享。
- 把自己的推论当成事实。
