# 方法卡片：情境领导与意愿能力矩阵

## 它解决什么问题
不同下属应该用不同的领导方式：根据每个人的能力和意愿，选择指令、教练、支持或授权。

## 什么时候用
- 带一个成员水平参差不齐的团队。
- 新人上岗、老员工状态下滑、准备给某人授权时。

## 什么时候不用
- 问题出在整个团队协作，而不是某个人：用团队协作五大障碍或 TOPIC。

## 四种下属状态与对应的领导方式
| 下属状态 | 领导方式 | 做法 |
|---|---|---|
| D1 能力弱，意愿高（新人） | S1 指令 | 明确告诉做什么、怎么做，密切跟进 |
| D2 能力弱到一般，意愿低（遇到挫折） | S2 教练 | 继续指导，同时多鼓励、多解释为什么 |
| D3 能力中到强，意愿不稳定 | S3 支持 | 少指导，多倾听、多参与决策、多给信心 |
| D4 能力强，意愿高 | S4 授权 | 放手让他做，只看结果 |

## 操作步骤
1. 针对**具体任务**判断下属状态（同一个人在不同任务上可能处于不同状态）。
2. 选择对应的领导方式。
3. 和下属沟通你将如何配合他。
4. 随着下属成长，逐步从指令走向授权。

## 输出模板
```
| 下属 | 任务 | 能力 | 意愿 | 状态 | 领导方式 | 具体做法 |
|---|---|---|---|---|---|---|
```

## 常见误用
- 对所有人用同一种方式。
- 给新人过早授权（放任），或者对骨干过度指令（打击积极性）。
- 只按人判断，不按任务判断。
