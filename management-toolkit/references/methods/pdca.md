# 方法卡片：PDCA 循环与标准化

## 它解决什么问题
让一项工作通过“计划、执行、检查、处理”的循环持续改进，每转一圈提升一步，并把有效的做法固定下来。

## 什么时候用
- 有标准、可重复的工作，需要持续提升质量或效率。
- 一个改进措施推出后，需要验证效果并推广。

## 什么时候不用，或换用什么
| 情况 | 换用 |
|---|---|
| 需求不确定、变化快的探索型工作 | 敏捷迭代 |
| 严重的质量或客诉问题，需要先止损 | 8D |
| 质量波动大，需要严格的数据证明 | 六西格玛 DMAIC |
| 只是事后快速总结经验 | AAR |

## 四个阶段（资料中细化为八个步骤）
- **P 计划**：1. 找出问题；2. 分析原因；3. 找出主要原因；4. 制定措施和计划（可以用 5W2H）。
- **D 执行**：5. 按计划实施。
- **C 检查**：6. 检查效果，与目标对比。
- **A 处理**：7. 把有效做法标准化，失败的教训记录下来；8. 遗留问题转入下一个循环。

## 操作步骤
1. 按上面八步走一轮。
2. 执行阶段要记录数据，否则检查阶段无从比较。
3. 处理阶段一定要做标准化：写进作业指导书、流程或制度，否则问题会反复出现。
4. 大循环套小循环：公司、部门、个人各有自己的 PDCA，互相推动。

## 输出模板
```
| 阶段 | 内容 | 负责人 | 时间 |
|---|---|---|---|
| 计划 | 问题：……  主因：……  措施：…… | | |
| 执行 | …… | | |
| 检查 | 目标 …… 实际 …… | | |
| 处理 | 标准化：……  转入下一轮：…… | | |
```

## 常见误用
- 只有 D 没有 P、C、A，也就是资料里说的“爱拼才会赢”式管理。
- 检查之后不标准化，下次又从头来。
- 一个循环做完就结束，没有进入下一轮。
