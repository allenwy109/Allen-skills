# 方法卡片：组织设计（星型模型）

## 它解决什么问题
设计或调整组织架构和运营模式，确保战略、结构、流程、激励和人员五个方面相互匹配。

## 什么时候用
- 战略调整后，组织需要跟着变。
- 新设部门、合并部门、业务重组。

## 什么时候不用
- 还不知道组织哪里出了问题：先用 consulting-analysis 的组织诊断（7S、六盒模型）。
- 只是个别岗位调整。

## 五个要素
1. **战略**：组织要实现什么方向和目标。
2. **结构**：权力和职责怎么划分（按职能、产品、地区、客户还是矩阵式）。
3. **流程**：信息和决策怎么在各部门之间流动。
4. **激励**：考核和奖励是否引导大家做战略需要的事。
5. **人员**：需要什么样的人和能力，怎么招、怎么培养。

## 操作步骤
1. 从战略出发，明确组织必须具备的核心能力。
2. 选择结构：比较几种结构方案的优缺点。
3. 设计关键流程和跨部门的协作机制。
4. 调整考核和激励，使之与新结构一致。
5. 盘点人员能力，制定人员配置和培养计划。
6. 检查五个要素是否一致：只改结构不改激励，是组织调整失败最常见的原因。

```
|---|---|---|---|
| 战略 | | | |
| 结构 | | | |

| 激励 | | | |

一致性检查：……
```

## 常见误用
- 只画组织架构图，其他四个要素不动。
- 因人设岗，而不是从战略出发。
