# 方法卡片：六顶思考帽与深度汇谈

## 它解决什么问题
会议讨论总是跑题、各说各话，或者变成争吵时，让所有人在同一时间用同一种方式思考。

## 怎么选
| 情况 | 用哪个 |
|---|---|
| 讨论需要高效地得出结论 | 六顶思考帽 |
| 团队需要把各自的潜在假设说出来、一起深入思考 | 深度汇谈 |

## 什么时候不用
- 深度汇谈不适合需要快速做决定的场合。
- 两三个人的简单讨论，不需要这么正式。

## 六顶帽子
- 蓝帽：控制流程，定议程、做总结（主持人戴）
- 白帽：只讲事实和数据
- 红帽：讲直觉和感受，不需要理由
- 黄帽：讲优点和价值
- 黑帽：讲风险和问题
- 绿帽：讲新想法和替代方案

## 操作步骤（六顶思考帽）
1. 蓝帽开场：明确议题和帽子的顺序。常用顺序：白 → 绿 → 黄 → 黑 → 红 → 蓝。
2. 每个阶段所有人戴同一顶帽子，只从这个角度发言。
3. 每顶帽子限定时间。
4. 蓝帽收尾：总结，做出决定。

## 深度汇谈
邀请大家自愿参加，围绕共同主题发言，把差异当成机会，说出彼此的不同看法，观察自己的思维，暂时“悬挂”自己的假设，共同创造新的理解。

## 输出模板
```
议题：……
| 帽子 | 要点 |
|---|---|
| 白（事实） | |
| 绿（新想法） | |
| 黄（优点） | |
| 黑（风险） | |
| 红（感受） | |
| 蓝（结论） | |
```

## 常见误用
- 有人一直戴着黑帽，否定一切。
- 帽子变成给人贴的标签（“他就是黑帽型的人”）。
