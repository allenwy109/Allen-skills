# 方法卡片：任务布置与计划（5W2H、WBS、日计划和周计划）

## 它解决什么问题
把一件事交代清楚、拆细、排进日程，避免“交代完才发现忘了说截止时间”这类遗漏。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 布置一项任务、出台一个方案，检查有没有漏掉要素 | 5W2H |
| 项目要拆成可以指派、可以估算工期的工作包 | WBS（工作分解结构） |
| 安排每天、每周的工作 | 日计划、周计划 |

## 什么时候不用
- 5W2H 只是一张检查清单，不负责排序；有很多任务要排先后时，用四象限或优选矩阵。

## 操作步骤（5W2H 布置任务）
- Why：为什么要做，目的是什么
- What：做什么，交付什么
- Who：谁负责，谁配合
- When：什么时候开始、什么时候完成、什么时候检查
- Where：在哪里做，从哪里入手
- How：怎么做
- How much：做到什么程度，预算多少
布置完请对方复述一遍。

## 操作步骤（WBS）
1. 把项目按交付物或阶段拆成几大块。
2. 每块继续拆，直到每个工作包能指派给一个人、能估算工期（一般不超过一到两周）。
3. 给每个工作包标明负责人、工期、前后依赖关系。

## 操作步骤（日计划）
资料建议每天的计划包括三部分：当天必须完成的重要工作、预留给会议和约定的时间、希望完成但优先级较低的待办事项。

## 输出模板
```
任务：……
| 要素 | 内容 |
|---|---|
| 为什么 | |
| 做什么 | |
| 谁 | |
| 何时 | |
| 何地 | |
| 怎么做 | |
| 多少 | |
```

## 常见误用
- 只说“做什么”，不说“做到什么程度”和“什么时候”。
- WBS 拆得太粗，工作包无法估算和跟踪。
