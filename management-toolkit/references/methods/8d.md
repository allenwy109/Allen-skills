# 方法卡片：8D 与碎石法（问题闭环管理）

## 它解决什么问题
对严重的质量、客诉或运营问题，建立一个从止损、找根因、永久纠正到防止复发的完整闭环。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 质量或客诉问题，需要团队协作、先止损再根治 | 8D |
| 想给企业建立一套统一的问题管理流程和模板 | 碎石法（七步） |

## 什么时候不用
- 小问题：用 PDCA 或 5WHY，8D 流程太重。

## 8D 步骤
- D1 组建团队：跨职能，有明确的负责人。
- D2 描述问题：用 5W2H 量化描述。
- D3 临时措施：先止损、隔离，保护客户。
- D4 根本原因：用鱼骨图和 5WHY 找出并验证根因，还要找出“为什么没被发现”的漏检点。
- D5 永久措施：针对根因选择并验证纠正措施。
- D6 实施与验证：执行永久措施，确认效果后撤除临时措施。
- D7 预防复发：修改流程、标准、防错设计，推广到类似产品或流程。
- D8 表彰团队：肯定团队的贡献。

资料对 8D 的概括是：源于生产，强调先扑火，再寻求长治久安的办法。

## 碎石法七步
问题界定 → 问题分解 → 原因分析 → 方案筛选 → 方案推进 → 效果评估 → 成果巩固。它是一家企业综合麦肯锡七步法、8D 和丰田问题解决法整理出来的，特点是每一步都配有表单模板，核心思想是“当问题分解到不能再分解时，问题就迎刃而解”。

## 输出模板
```
| 步骤 | 内容 | 负责人 | 完成日期 |
|---|---|---|---|
| D1 团队 | | | |
| D2 问题 | | | |
| D3 临时措施 | | | |
| D4 根因（含漏检点） | | | |
| D5 永久措施 | | | |
| D6 实施验证 | | | |
| D7 预防复发 | | | |
| D8 表彰 | | | |
```

## 常见误用
- 跳过 D3，客户还在持续受影响。
- D4 只找发生原因，不找漏检原因。
- D7 敷衍，同类问题在别的产品线再次出现。
