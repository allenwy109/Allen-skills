# 方法卡片：目标多叉树与 6W3H

## 它解决什么问题
把一个大目标一层层分解成必要且充分的子目标，再细化成具体行动。

## 什么时候用
- 目标已经确定，但太大，不知道从哪里下手。
- 需要把团队目标分解到每个人。

## 什么时候不用
- 目标本身还没定：先用 SMART、OKR 或平衡计分卡。

## 操作步骤
1. 写出大目标。
2. 写出实现大目标的所有必要且充分的条件，这就是子目标。
3. 对每个子目标，再写出它的必要且充分的条件，直到分解成可以立即执行的“即时目标”。
4. 检查：如果所有子目标都达成，大目标是否一定能达成？（检查分解是否充分）
5. 用 6W3H 把每个即时目标细化：
   - Why：为什么做
   - What：做什么
   - Who：谁来做，谁协助
   - When：什么时候完成
   - Where：在哪里做
   - Which：先做哪个，重点在哪
   - How to：怎么做，步骤顺序
   - How many：数量多少
   - How much：预算多少
6. 每个子目标再过一遍 SMART。

## 输出模板
```
大目标：……
├─ 子目标 1：……
│   ├─ 即时目标 1.1：……（谁、何时、怎么做、预算）
│   └─ 即时目标 1.2：……
└─ 子目标 2：……
充分性检查：……
```

## 常见误用
- 分解得不充分，所有子目标都做完了，大目标还是达不成。
- 只分解不分工，最后没有人负责。
