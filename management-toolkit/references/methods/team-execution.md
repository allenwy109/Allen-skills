# 方法卡片：团队执行与协作（管理 4C、TOPIC、团队协作五大障碍）

## 它解决什么问题
团队执行力差、协作不畅时，找出问题出在哪个环节。

## 怎么选
| 情况 | 用哪个 |
|---|---|
| 任务布置了，结果总是不到位 | 管理 4C |
| 团队管理出了问题，但说不清是哪里 | TOPIC（逐项排查） |
| 表面和气，但事情推不动；开会不说真话 | 团队协作五大障碍 |

## 什么时候不用
- 问题出在个别人身上：用情境领导。
- 问题出在组织结构或制度：用 consulting-analysis 的组织诊断。

## 管理 4C
- 澄清（Clarity）：布置任务要清晰（可以用 5W2H）。
- 承诺（Commitment）：让执行者真心认同并承诺。
- 胜任（Competence）：辅导到位，确保他有能力做。
- 控制（Control）：设定检查点，全面跟进。
逐项检查哪一个 C 没做到。

## TOPIC
信任（Trust）、目标（Objective）、流程（Process）、承诺（Commitment）、沟通（Communication）。逐项给团队打分，找出最弱的一项。

## 团队协作五大障碍（从下往上）
1. 缺乏信任：不敢暴露弱点和错误
2. 惧怕冲突：回避有建设性的争论
3. 欠缺投入：没有真正的承诺，决定了也不执行
4. 逃避责任：不愿意指出同事的问题
5. 忽视结果：只顾个人或部门利益
从最底层的信任开始排查；底层不解决，上层很难改善。

## 输出模板
```
| 维度 | 现状评分（1-5） | 具体表现 | 改进措施 |
|---|---|---|---|
最薄弱环节：……
```

## 常见误用
- 一有问题就归结为“执行力差”，不深究是哪个环节。
- 跳过信任，直接要求大家“要负责任”。
