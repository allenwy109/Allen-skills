# 方法卡片：GROW 教练模型

## 它解决什么问题
下属来求助或需要辅导时，不直接给答案，而是通过提问帮他自己理清目标、看清现状、找到方案、下定决心。

## 什么时候用
- 下属有一定能力，但遇到了困难或迷茫。
- 一对一辅导、绩效面谈、职业发展谈话。

## 什么时候不用
- 下属能力很弱、完全不知道怎么做：先直接指导（见情境领导卡片）。
- 情况紧急，需要立刻决定：直接给指令。

## 四个步骤和常用问题
1. **目标（Goal）**：你想达到什么？怎样算成功？
2. **现状（Reality）**：现在的情况怎样？已经试过什么？有哪些困难和资源？
3. **方案（Options）**：还有哪些可能的做法？如果没有任何限制，你会怎么做？每个方案的利弊是什么？
4. **意愿与行动（Will / Wrap-up）**：你会选哪个？第一步是什么？什么时候开始？需要我提供什么支持？你有多大把握（1 到 10 分）？

## 操作步骤
1. 约一个不被打扰的时间。
2. 按四步提问，多听少说，不急于给建议。
3. 帮对方拓展思路，看到他自己没看到的可能性。
4. 最后让对方自己说出行动计划，并约定跟进时间。

## 输出模板（谈话提纲）
```
目标：……？
现状：……？
方案：……？
行动：第一步 ……，时间 ……，需要的支持 ……
跟进时间：……
```

## 常见误用
- 问着问着就变成了说教。
- 跳过现状直接讨论方案。
- 没有落到具体行动和跟进。
