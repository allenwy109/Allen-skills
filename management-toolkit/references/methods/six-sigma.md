# 方法卡片：六西格玛 DMAIC

## 它解决什么问题
用数据和统计方法，系统地降低流程波动和缺陷率。

## 什么时候用
- 质量问题反复出现，原因不明，需要用数据证明。
- 改进的收益大，值得投入较多时间和分析资源。

## 什么时候不用
- 问题简单、原因明显：用 PDCA 或 5WHY 即可，DMAIC 太重。
- 缺乏基础数据，也没有条件收集。

## 五个阶段
1. **定义（D）**：明确问题、客户要求、项目范围和目标（可以用 SIPOC）。
2. **测量（M）**：确认测量系统可靠，收集基线数据，算出当前缺陷率。
3. **分析（A）**：用鱼骨图、帕累托图、相关分析等找出根本原因，并用数据验证。
4. **改进（I）**：设计并试验改进方案，验证效果。
5. **控制（C）**：用控制图、标准作业、防错措施把成果保持住。

## 输出模板
```
| 阶段 | 关键产出 | 结果 |
|---|---|---|
| 定义 | 问题陈述、目标 | |
| 测量 | 基线缺陷率 | |
| 分析 | 验证过的根因 | |
| 改进 | 改进方案及效果 | |
| 控制 | 控制计划 | |
```

## 常见误用
- 跳过测量阶段，凭经验下结论。
- 为了做项目而做项目，选的问题收益太小。
- 控制阶段敷衍，成果很快反弹。
