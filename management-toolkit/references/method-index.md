## 1. 目标设定与分解

### SMART
- 是什么：具体、可衡量、可实现、相关、有时限。
- 什么时候用：检查任何一个目标写得好不好。
- 常见误用：“可实现”被理解成“稳拿”，结果目标定得过低。资料里的说法是“跳起来摘桃子，而不是摘星星”。
- 出处：【资料】SMART 3 个文件及多份工具箱。

### OKR 与 KPI
- OKR 适合：探索型（从 0 到 1）、知识型、创新型工作；自驱型员工；变化快、需要按季度调整的环境。
- KPI 适合：推算型（从 1 到 N）、标准化、可重复的工作；日常经营状况的监控。
- 要点：OKR 用于对齐方向和自我管理，不宜直接挂钩考核；两者可以叠加使用，KPI 管日常，OKR 管突破。
- 出处：【资料】OKR 6 个文件；【网络】OKR、KPI、平衡计分卡对比文章。

### 平衡计分卡与战略地图
- 是什么：从财务、客户、内部流程、学习与成长四个层面设定目标和指标；战略地图把四个层面的因果关系画出来。
- 什么时候用：成熟企业要把战略翻译成各层面的衡量指标，并与预算和资源分配挂钩。
- 与 OKR 的关系：平衡计分卡回答“往哪走、衡量什么”，OKR 回答“这个季度怎么推进”，二者可以配合使用。
- 出处：【贝恩】【网络】。

### 方针管理（Hoshin Kanri）/ OGSM
- 是什么：把少数几个突破性目标从高层逐层分解到部门和个人。OGSM（目的、目标、策略、衡量）是一页纸的简化版本。
- 什么时候用：战略周期有三到五年、需要跨部门协作的变革；不希望目标按季度频繁调整时。
- 出处：【网络】。

### 目标多叉树 / 6W3H
- 什么时候用：把大目标逐层分解成必要且充分的子目标，再细化到行动。
- 出处：【资料】《基层管理者管理工具箱》。

## 2. 计划与分工

### 5W2H
- 什么时候用：布置任务、制定计划、出台方案时，检查有没有遗漏要素。资料里的典型场景是：交代完任务才发现忘了说截止时间。
- 局限：它只是一张检查清单，不负责排序。
- 出处：【资料】5W2H 相关 6 个文件。

### WBS（工作分解结构）
- 什么时候用：项目要拆成可以指派、可以估算工期的工作包。
- 出处：【网络】补充。

### RACI
- 是什么：每一项工作标明执行者（R）、负责人（A）、需要咨询的人（C）、需要知会的人（I）。
- 什么时候用：多人或跨部门协作时职责不清、互相推诿。
- 要点：每件事只能有一个 A。
- 出处：【网络】补充。

### 日计划 / 周计划
- 什么时候用：个人或小组的日常工作安排。
- 出处：【资料】《基层管理者管理工具箱》《如何制定工作计划》。

## 3. 执行与持续改进

### PDCA
- 什么时候用：有标准、可重复的工作的持续改进，每转一圈提升一步。做完一轮要把有效做法标准化，再进入下一轮。
- 与 AAR 的区别：PDCA 更正式、更完整；AAR 可正式也可随意；两者不能互相替代。
- 出处：【资料】PDCA 4 个文件、《联想AAR复盘资料》。

### 标准化管理
- 什么时候用：把 PDCA 中验证有效的做法固定下来，防止问题反复。
- 出处：【资料】《基层管理者管理工具箱》。

### 精益（八大浪费、价值流图）
- 什么时候用：流程慢、库存多、等待多、返工多。
- 出处：【资料】《精益生产之5M1E分析法》（部分）；【网络】Umbrex 运营类框架。

### 六西格玛 DMAIC
- 是什么：定义、测量、分析、改进、控制。
- 什么时候用：质量波动大、需要严格用数据证明改善效果的问题。
- 不适用：简单问题，流程太重。
- 出处：【网络】补充。

### SIPOC
- 是什么：供应商、输入、流程、输出、客户。
- 什么时候用：改进一个流程之前，先画出它的边界和上下游。
- 出处：【网络】Umbrex。

### 5S / 6S
- 什么时候用：现场管理基础（整理、整顿、清扫、清洁、素养，再加安全）。
- 出处：【资料】《6S管理方法与技巧培训》。

### 敏捷管理
- 什么时候用：需求不确定、变化快的工作，用短周期迭代、频繁回顾来调整方向。
- 出处：【贝恩】。

## 4. 问题分析与根因

### 问题 = 标准 − 现状
- 是什么：问题就是现状与应有状态之间的差距。分为发生型（已偏离标准）和设定型（主动拔高目标）。
- 什么时候用：先把“现象”和“问题”分开，避免把症状当问题。正确的问题描述要具体、客观、有数据，不要带着解决方案，也不要用疑问句。
- 出处：【资料】《问题分析与解决8大方法》《“碎石法”》《问题分析与解决方法》。

### 优选矩阵 / 帕累托图
- 什么时候用：同时有很多问题，要决定先解决哪个。优选矩阵按重要、紧急、变化程度打分；有数据时用帕累托图找出影响最大的少数问题。
- 出处：【资料】《问题分析与解决方法（48P）》《PDCA管理循环（114P）》。

### 5WHY、鱼骨图、5M1E
- 5WHY：现象清楚、原因接近单一时使用。
- 鱼骨图：原因多、涉及多个环节时使用；制造和质量问题常用 5M1E 作为大骨。
- 两者配合：先用鱼骨图求广度，再对主要原因用 5WHY 求深度。
- 出处：【资料】5WHY、鱼骨图、5M1E 相关文件；【网络】根因分析对比文章。
- 卡片：`methods/root-cause.md`

### 8D
- 什么时候用：质量或客诉问题，需要组建团队、先临时止损、再找根因、永久纠正并防止复发。
- 不适用：简单问题。
- 出处：【资料】《问题分析与解决8大方法》《“碎石法”》。

### 碎石法（问题管理七步）
- 是什么：问题界定 → 问题分解 → 原因分析 → 方案筛选 → 方案推进 → 效果评估 → 成果巩固。这是某企业综合麦肯锡七步法、8D 和丰田问题解决法整理出的内部方法论。
- 什么时候用：需要给企业建立一套统一的问题管理流程和模板时，可以参考它。
- 出处：【资料】《“碎石法”问题分析与解决》。

### 奖惩分析法
- 什么时候用：找出工作中被忽视的关键因素，把因素分为“做好了加分”和“做不好扣分”两类。
- 出处：【资料】《问题分析与解决8大方法》。这个方法比较少见，使用前先确认对用户有帮助。

## 5. 复盘

### 复盘四步法（GRAI）
- 步骤：回顾目标 → 评估结果（亮点与不足） → 分析原因 → 总结规律。
- 要点：从梳理最初目标开始；先检查目标本身是否定错；分析失败原因时多从自身找；总结规律要谨慎，不能把一时一地的经验当成规律。
- 常见误区：为了证明自己对、走过场、变成追责。
- 出处：【资料】复盘相关 5 个文件。

### AAR（行动后反思）
- 是什么：美军的做法，回答四个问题：预期是什么、实际发生了什么、为什么有差异、下次怎么做。
- 什么时候用：正式场合用完整版；会议或活动结束时可以花 5 分钟做非正式版本。
- 出处：【资料】《联想AAR复盘资料》《复盘：把经验转化为能力》。

## 6. 带人与团队

### GROW 教练模型
- 什么时候用：下属来求助，或者需要辅导下属自己想清楚。
- 不适用：下属能力很弱时，先直接指导。
- 出处：【资料】《20种思维与领导能力模型速览》《常用的六大管理模型》。

### 情境领导 / 意愿与能力矩阵
- 什么时候用：根据下属的能力和意愿，分别采用指令、教练、支持、授权四种方式。
- 出处：【资料】《20种思维与领导能力模型速览》《基层管理者管理工具箱》。

### 管理 4C / TOPIC
- 4C：布置清晰、真心承诺、辅导到位、全面控制，用于提升团队执行力。
- TOPIC：信任、目标、流程、承诺、沟通，用于排查团队管理问题出在哪个要素。
- 出处：【资料】《20种思维与领导能力模型速览》。

### 团队协作五大障碍
- 是什么：缺乏信任 → 惧怕冲突 → 欠缺投入 → 逃避责任 → 忽视结果，从下往上层层递进。
- 什么时候用：团队协作不畅、表面和气但推不动事情。
- 出处：【网络】组织发展类工具。

### 领导梯队
- 什么时候用：规划管理者从管理自己到管理公司的成长路径，找出下一个阶段需要补的能力。
- 出处：【资料】《20种思维与领导能力模型速览》。

### 马斯洛需求层次 / 员工敬业度调查
- 什么时候用：员工积极性低，要找出是哪一层需求没有得到满足；敬业度调查用来找出哪些投入对提升敬业度最有效。
- 出处：【资料】《基层管理者管理工具箱》；【贝恩】。

### 乔哈里视窗
- 什么时候用：沟通不畅时，扩大双方都知道的“公开区”，减少盲区和隐藏区。
- 出处：【资料】《表达力与创造力模型速览》《基层管理者管理工具箱》。

## 7. 组织设计与变革

### 星型模型（Galbraith）
- 是什么：战略、结构、流程、激励、人员五个方面要相互匹配。
- 什么时候用：设计或调整组织架构和运营模式。建议先用六盒模型或 7S 找到问题，再用星型模型设计目标状态。
- 出处：【网络】Umbrex、组织诊断模型对比。

### Kotter 变革八步法
- 是什么：营造紧迫感 → 组建领导联盟 → 形成愿景 → 沟通愿景 → 扫除障碍 → 创造短期成果 → 巩固成果、推进变革 → 固化到文化中。
- 什么时候用：推进全公司层面的变革，需要一个整体的推进顺序。
- 出处：【网络】补充。

### ADKAR
- 是什么：认知、意愿、知识、能力、巩固。
- 什么时候用：变革中个别员工或团队跟不上，要找出他们卡在哪一步。
- 出处：【网络】补充。

### 力场分析
- 什么时候用：变革启动前，列出推动力和阻力，评估可行性并制定削弱阻力的办法。
- 出处：【网络】Umbrex。

### 勒温三阶段
- 是什么：解冻、变革、再冻结。
- 什么时候用：最简单的变革框架，适合向团队解释变革的节奏。
- 出处：【网络】补充。

## 8. 会议与集体讨论

### 头脑风暴 / 635 法
- 头脑风暴：需要大量新点子时使用。规则是不评价、越多越好、可以借别人的想法延伸。
- 635 法：6 人，每人每轮写 3 个点子，每轮 5 分钟，传给下一个人。适合敏感话题，或者怕少数人主导讨论时。
- 出处：【资料】头脑风暴相关 3 个文件。

### 六顶思考帽
- 什么时候用：会议讨论总是跑题或变成争吵时，让所有人在同一时间只用同一种思考方式（事实、情感、风险、价值、创意、总结）。
- 出处：【资料】六顶思考帽相关文件。

### SCAMPER / 逆向思维 / 类比思维
- 什么时候用：改进现有产品、服务或流程时，用来产生新点子。
- 出处：【资料】《表达力与创造力模型速览》。

### 深度汇谈
- 什么时候用：团队需要把各自的潜在假设说出来、一起深入思考时。不适合需要快速决策的场合。
- 出处：【资料】《基层管理者管理工具箱》。

## 9. 个人效率方法

四象限、80/20、GTD、番茄工作法、高效能人士的七个习惯等个人方法，已经单独整理成 personal-effectiveness skill。本 skill 只处理团队和组织层面的管理问题。
