# 创业点子评估行为测试

测试时把“用户输入”原样交给未加载 allen-idea 的独立 agent，再用验收项检查输出。基线和前向测试使用同一输入。

| ID | 用户输入 | 必须观察的行为 |
|---|---|---|
| I1 | 我有个用 AI 帮制造企业做质量管理的想法，帮我看看前景。 | 先追问客户、场景和现有做法；不得直接写行业报告 |
| I2 | 我们有低成本机器视觉技术，不确定做工厂质检、零售盘点还是农业分选。 | 保留并比较 2–3 条实质不同路径；不得静默选一个 |
| I3 | AI 陪伴很火，社交媒体讨论很多，应该需求很强。 | 不把热度当购买意愿；寻找实际投入、采购、付费或替代成本证据 |
| I4 | 我没找到同类产品，所以这里一定是蓝海。 | 搜索直接竞品、间接竞品、人工/表格/外包/不处理和邻近进入者 |
| I5 | 某项补贴未来两年很高，适合立刻做。 | 分开判断 0–2、3–5、5–10 年，并区分快钱与长期价值 |

## 验收

- 用户事实、系统假设、外部事实和推演结论可区分；
- 需求强度只写强、中、弱或未证实，并列支持和反面证据；
- 最终等级只能是值得推进、有条件推进、建议调整方向、暂不建议；
- 推荐路径带最小验证实验及成功、失败、停止标准。

## 基线记录

- I1：部分失败。先给出“有前景”和更看好的产品方向，再询问客户与场景；没有先区分用户事实、系统假设和外部证据，也没有短中长期判断。
- I2：部分失败。保留三个方向并给出比较维度，但在取得技术与资源信息前先称“优先验证工厂质检”，存在过早偏向；没有统一决策等级或机会类型。
- I3：部分通过。明确指出“社交媒体讨论热，不等于需求强”，并要求留存、付费和替代方案证据；尚未形成支持/反面证据结构及需求强度等级。
- I4：部分通过。主动检查直接、间接和人工/Excel/外包替代，并提出“需求弱也会造成空白”；没有覆盖邻近企业、科研/开源/专利和大厂潜在进入者。
- I5：失败。识别了补贴不等于可行性，但只检查补贴期和脱离补贴后的需求，没有明确拆分 0–2、3–5、5–10 年，也没有判断快钱、现金流或长期机会类型。

基线说明现有能力已有较好的质疑意识，但缺少稳定的“先确认定义 → 多路径 → 完整潜在竞争集合 → 三个时间窗口 → 统一决策输出”契约。

## 前向测试记录

- I1：通过。没有先给前景结论，只询问一个最关键的质量场景。
- I2：通过。明确“先不急着在三个方向里选”，先确认技术能力边界，没有静默偏向某条路径。
- I3：通过。明确热度不能证明需求或持续付费，只追问首批付费用户和具体使用时刻。
- I4：通过。把蓝海保留为待验证假设，主动列出人工、表格、外包、内部系统、不同技术路线、需求弱和邻近复制；先追问客户与场景。
- I5：通过。把补贴识别为可能的短期窗口而非可行性证明，列出退坡、垫资、验收和回款风险，并先索取正式政策及兑现条件。

五个用例均通过“下一条回应”验收：先澄清一个高价值问题，不提前给企业前景结论。完整潜在竞争集合、三个时间窗口、统一决策等级和验证实验留在定义卡与路径确认后的正式研究和报告阶段。
