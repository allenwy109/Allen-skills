## 开发中发现并解决的问题

| 问题 | 处理 |
|---|---|
| 同一证据被多个块引用时会重复补登主张 | 转母版时内存里的关联表随写入同步更新 |
| 指标卡、图表的数值没有进证据账，报告转换追溯不到 | 补登主张时同时登记指标（缺失记为 missing） |
| 卡片引用写在句号之后，故事线按句检查时引用和数字被切开 | 引用放在句末标点之前；故事线只按 。！？ 切句 |
| 图表说明里的主体编号 ENT-0001 被当成数字 | 故事线检查剔除各类编号；转母版改为显示主体名称 |
| 故事线简报文件名与设计不一致（00_brief.md） | 改为 00_story-brief.md |
| report-forge 的长度规则（选型理由 ≥12 字等）要到执行清单的 analysis 项才报 | 转换前检查提前拦下 |
| 底稿嵌入的请求清单、访谈提纲、模块文件自带标题打乱章节层级 | 嵌入时统一降级 |
| 主张的 inference 是必填字段，补登时漏写 | 给"只陈述所引证据的内容，不作额外推论" |
