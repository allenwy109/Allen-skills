# 方法卡片：竞争战略（波特通用战略、战略钟、价值信条、价值链）

## 它解决什么问题
回答“我们凭什么和对手竞争、竞争优势来自哪一环”。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 选择基本的竞争方式 | 波特通用战略（成本领先、差异化、聚焦） |
| 想在价格和附加值组合上找更细的定位 | 战略钟（8 种组合） |
| 想明确在哪个维度上做到极致 | 价值信条（运营卓越、产品领先、亲密客户） |
| 想知道优势或成本来自哪个环节 | 波特价值链 |

## 什么时候不用
- 行业本身不值得做：先用五力判断。
- 市场高度同质化、只能拼价格：考虑蓝海战略。

## 操作步骤
1. **看现状**：我们现在的价格和附加值相对竞争对手处在什么位置（可以画在战略钟上）。
2. **选基本战略**：成本领先、差异化，还是在某个细分市场聚焦。避免“夹在中间”：既不便宜也没有特色。
3. **定价值信条**：三个维度中选一个做到行业最好，另外两个达到行业平均水平即可。
4. **用价值链检验**：选定的战略需要哪些环节做得特别好？我们现在这些环节的能力如何？
   - 主要活动：进货物流、生产运营、出货物流、市场销售、服务
   - 支持活动：采购、技术开发、人力资源、基础设施
5. **找出要加强和可以放弃的环节**。

## 输出模板
```
当前定位：价格 ……，附加值 ……（战略钟位置：……）
选择的竞争战略：……（理由：……）
价值信条：做到极致的维度 ……
价值链检验：
| 环节 | 对战略的重要性 | 我们的能力 | 行动 |
```

## 常见误用
- 什么都想要：又要最便宜又要最好。
- 说自己是差异化，但客户感受不到差别。
- 价值链只画图，不和战略选择挂钩。
