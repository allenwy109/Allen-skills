# 方法卡片：增长路径（安索夫矩阵、增长七个自由度、增长三层面）

## 它解决什么问题
回答“下一步靠什么增长、愿意承担多大风险、长短期怎么平衡”。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 在产品和市场两个维度上选增长方向 | 安索夫矩阵 |
| 想系统盘点所有可能的增长途径 | 增长七个自由度 |
| 要平衡核心业务、新兴业务和未来机会的资源 | 增长三层面 |

## 什么时候不用
- 增长问题的根源是现有业务在流失客户：先用利润树或 3C 诊断，而不是急着找新增长点。

## 操作步骤
**安索夫矩阵**
| | 现有产品 | 新产品 |
|---|---|---|
| 现有市场 | 市场渗透（风险最低） | 产品开发 |
| 新市场 | 市场开发 | 多元化（风险最高） |
1. 把每个增长想法放进对应的格子。
2. 评估每个想法的潜力、所需能力和风险。
3. 一般先挖掘低风险的市场渗透；多元化需要有充分的能力支撑。

**增长七个自由度**：扩大现有市场份额、推出新产品或服务、进入新渠道、开拓新地域、服务新客户群、向价值链上下游延伸、进入相关的新业务。逐项检查是否被忽略。

**增长三层面**
- 第一层：拓展和守住核心业务，看利润和投资回报。
- 第二层：发展正在成长的新业务，看收入增长和净现值。
- 第三层：为未来的业务机会下注，看期权价值。
三层同时需要投入，只顾第一层会失去未来，只顾第三层会失去现在。

## 输出模板
```
| 增长想法 | 类型（渗透/市场开发/产品开发/多元化） | 潜力 | 所需能力 | 风险 | 优先级 |
|---|---|---|---|---|---|
三层面资源分配：第一层 ……%，第二层 ……%，第三层 ……%
```

## 常见误用
- 所有想法都往多元化里放，低估风险。
- 只列想法，不评估自身能力是否匹配。
- 三个层面用同一套指标考核，导致新业务被过早砍掉。
