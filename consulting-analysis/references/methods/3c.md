# 方法卡片：3C（公司、客户、竞争对手）

## 它解决什么问题
从公司自身、客户、竞争对手三个角度看问题，找到竞争优势所在。适合回答份额、竞争地位、客户类问题。

## 什么时候用
- 市场份额下降、客户流失、竞争对手突然发力。
- 品牌定位、竞争策略的讨论。

## 什么时候不用
- 纯成本或运营效率问题：用利润树、价值链或精益。
- 行业整体吸引力问题：用五力。

## 操作步骤
1. **客户**：客户是谁、有哪些细分群体、需要什么、购买决策怎么做、需求有什么变化。
2. **竞争对手**：主要对手是谁、他们做了什么、为什么做得比我们好或差、下一步可能怎么做。
3. **公司**：我们的产品、能力、成本、渠道、品牌相对对手如何。
4. **找交叉点**：客户需要的、我们能提供的、对手提供不好的，就是机会所在；客户需要的、对手比我们做得好的，就是问题所在。
5. **得出结论和行动**。

## 输出模板
```
客户：细分 ……；需求变化 ……
竞争对手：…… 做了 ……，效果 ……
我们：优势 ……；短板 ……
机会：……
问题：……
建议：……
```

## 常见误用
- 三个部分各自描述，没有交叉比较。
- 只看现在的竞争对手，忽略新进入者和替代品。
- 客户部分只写人口统计特征，不写需求和购买行为。
