# 方法卡片：利益相关者分析

## 它解决什么问题
重大决策或变革之前，识别谁会受影响、谁会支持、谁会反对、谁的话最有分量，从而提前做好沟通和争取。

## 什么时候用
- 推动涉及多个部门或外部方的方案。
- 方案本身没问题，但担心推不下去。

## 什么时候不用
- 方案只涉及个人或一个小团队。

## 操作步骤
1. **列出所有相关方**：内部（高层、各部门、员工），外部（客户、供应商、政府、股东、媒体）。
2. **评估每一方**：影响力（高或低）和态度（支持、中立、反对）。
3. **放进矩阵**：
   - 影响力高、支持：依靠他们，请他们帮忙推动
   - 影响力高、反对：重点沟通，了解顾虑，争取或化解
   - 影响力低、支持：保持信息同步
   - 影响力低、反对：关注动向，避免扩散
4. **了解诉求**：每个关键相关方最在意什么，方案能给他们带来什么、让他们失去什么。
5. **制定沟通计划**：谁去沟通、什么时候、说什么。

## 输出模板
```
| 相关方 | 影响力 | 态度 | 关注点 | 争取策略 | 负责人 |
|---|---|---|---|---|---|
最需要争取的：……
```

## 常见误用
- 只列不动，没有转化成沟通行动。
- 凭印象判断态度，没有实际去了解。
- 忽视“沉默的反对者”。
