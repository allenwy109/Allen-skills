# 方法卡片：利润树、价值树与杜邦分析

## 它解决什么问题
把一个财务结果（利润、收入、投资回报率）按公式一层层拆开，找到到底是哪个驱动因素出了问题，或者哪个杠杆最值得拉。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 利润、收入、毛利下滑，要找原因 | 利润树 |
| 想找业绩改善的杠杆，或者设计考核指标 | 价值树（驱动因素树） |
| 想知道股东回报高低来自哪里 | 杜邦分析 |

## 什么时候不用
- 问题不是财务结果，而是组织、文化、战略方向时。
- 数据完全拿不到时，公式拆解会变成空架子，改用定性的议题树。

## 操作步骤（利润树）
1. **写公式**：利润 = 收入 − 成本。
2. **拆收入**：收入 = 销量 × 单价；销量可以再按产品、客户、渠道、地区拆。
3. **拆成本**：固定成本 + 可变成本；或按价值链环节（采购、生产、物流、销售、管理）拆。
4. **看趋势和对比**：每个分支都看历史变化，并和竞争对手、行业平均比。
5. **判断是自身问题还是行业问题**：如果整个行业都在下滑，重点就是应对外部变化，而不是内部改进。
6. **定位后再深挖**：在变化最大的分支上继续问“为什么”，必要时切换到 3C（收入侧）或价值链、标杆分析（成本侧）。

杜邦分析：净资产收益率 = 销售净利率 × 资产周转率 × 权益乘数，分别对应盈利能力、运营效率和财务杠杆。

价值树：从投资资本回报率往下拆到收入、成本、营运资本、固定资产等可管理的驱动因素；设计考核指标时，从中挑 5 到 10 个最关键的。

## 输出模板
```
利润变化：去年 …… → 今年 ……（变化 ……）
├─ 收入：…… → ……
│   ├─ 销量：……（按产品/客户/渠道：……）
│   └─ 单价：……
└─ 成本：…… → ……
    ├─ 固定成本：……
    └─ 可变成本：……
行业对比：……
主要原因：……（需要进一步验证：……）
```

## 常见误用
- 只拆不比：没有历史趋势和行业对比，看不出哪个分支有问题。
- 只看收入侧或只看成本侧。
- 拆出来之后每个分支都去分析，没有用 80/20 聚焦。
- 忽视结构变化：单价没变，但高价产品占比下降，平均单价也会下降。
