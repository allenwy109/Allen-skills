# 方法卡片：商业模式画布

## 它解决什么问题
用一张图把一个商业模式的九个要素讲清楚，方便描述、比较和重新设计商业模式。

## 什么时候用
- 描述新业务或初创企业的商业模式。
- 比较自己和竞争对手的模式差异。
- 讨论商业模式要不要调整、怎么调整。

## 什么时候不用
- 需要评估模式好坏：画布只是描述工具，要结合五力、利润树或市场规模来判断。

## 九个模块
1. 客户细分：为谁创造价值
2. 价值主张：为客户解决什么问题
3. 渠道：怎么触达客户
4. 客户关系：怎么维系客户
5. 收入来源：客户为什么付钱、怎么付
6. 核心资源：必须拥有什么
7. 关键业务：必须做好什么
8. 重要合作：需要谁的帮助
9. 成本结构：主要的钱花在哪里

## 操作步骤
1. 从客户细分和价值主张开始，这两个是核心。
2. 再填渠道、客户关系、收入来源（面向客户的右半部分）。
3. 最后填核心资源、关键业务、重要合作、成本结构（支撑的左半部分）。
4. 检查一致性：左半部分能否支撑右半部分？收入能否覆盖成本？
5. 如果要重新设计，每次只改一两个模块，看会引起哪些连锁变化。

## 输出模板
```
| 重要合作 | 关键业务 | 价值主张 | 客户关系 | 客户细分 |
|         | 核心资源 |         | 渠道     |         |
| 成本结构             |         收入来源            |
主要风险或不一致之处：……
```

## 常见误用
- 价值主张写成产品功能清单，而不是客户得到的好处。
- 客户细分写“所有人”。
- 各模块之间互不相关，不是一个完整的逻辑。
