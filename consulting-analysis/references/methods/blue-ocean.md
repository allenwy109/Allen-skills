# 方法卡片：蓝海战略

## 它解决什么问题
市场拥挤、只能拼价格时，通过重新组合行业的竞争要素，开辟没有直接竞争的新市场空间。

## 什么时候用
- 行业高度同质化，价格战严重。
- 想开发新品类，或重新定义现有产品。

## 什么时候不用
- 行业还在快速增长，现有打法仍然有效。
- 缺乏对客户需求的深入了解，重构容易变成闭门造车。

## 操作步骤
1. **画战略布局图**：横轴列出行业竞争的主要要素（价格、功能、服务、渠道等），纵轴是投入程度，画出行业主流企业的曲线。
2. **看非客户**：谁不买这个行业的产品？为什么？
3. **四步动作框架（剔除、减少、增加、创造）**：
   - 剔除：哪些行业默认必须有的要素其实可以去掉？
   - 减少：哪些要素可以降到行业标准以下？
   - 增加：哪些要素应该提高到行业标准以上？
   - 创造：哪些行业从未提供过的要素应该创造出来？
4. **画出新的价值曲线**：和行业曲线明显不同，有焦点，有一句话能说清的口号。
5. **检验商业可行性**：价格、成本、推广是否行得通。

## 输出模板
```
| 竞争要素 | 行业水平 | 我们的新做法 | 动作（剔除/减少/增加/创造） |
|---|---|---|---|
新的价值主张（一句话）：……
可行性检验：……
```

## 常见误用
- 只做加法（增加、创造），不做减法，成本失控。
- 新的价值曲线和行业差别不大。
- 把“小众市场”误当成蓝海。
