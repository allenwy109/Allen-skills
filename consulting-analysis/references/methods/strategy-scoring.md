# 方法卡片：战略打分矩阵（IFE、EFE、IE、SPACE、大战略矩阵、QSPM）

## 它解决什么问题
把 SWOT 的定性判断量化，并在多个备选战略之间做比较和选择。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 想给内部优劣势打分 | IFE（内部因素评价矩阵） |
| 想给外部机会威胁打分 | EFE（外部因素评价矩阵） |
| 多业务企业，想判断各业务该增长、维持还是收缩 | IE 矩阵（用 IFE、EFE 总分定位九宫格） |
| 想判断整体战略姿态：进取、保守、防御还是竞争 | SPACE（战略地位与行动评价矩阵） |
| 根据市场增长和竞争地位找可选战略 | 大战略矩阵 |
| 已有几个备选战略，要挑出最好的 | QSPM（定量战略计划矩阵） |

## 什么时候不用
- 定性判断已经足够清楚，打分只是走形式。
- 团队对关键因素和权重没有共识：先讨论清楚，否则分数没有意义。

## 操作步骤（IFE / EFE，其余矩阵方法类似）
1. 选出 10 到 20 个关键因素（IFE 为优势和劣势，EFE 为机会和威胁）。
2. 按每个因素对行业成功的重要程度赋予权重，总和为 1。
3. 给企业在每个因素上的表现打分（1 到 4 分）。
4. 权重 × 评分，加总得出总分；2.5 分为平均水平，越接近 4 分越好。
5. QSPM：对每个备选战略，逐个因素评估它的吸引力（1 到 4 分），乘以权重后加总，总分最高的战略最优。

## 输出模板
```
| 关键因素 | 权重 | 评分 | 加权分 |
|---|---|---|---|
| 优势 1：…… | 0.10 | 4 | 0.40 |
| …… | | | |
| 合计 | 1.00 | | 2.8 |
结论：……
```

## 常见误用
- 关键因素选得主观，结论跟着偏（资料特别强调这一点）。
- 把 2.8 分和 2.7 分的差别当成真实差距；这类矩阵只适合看大方向。
- 机会和威胁往往是一件事的两面，很难达成一致，需要事先约定口径。
