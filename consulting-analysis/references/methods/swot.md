# 方法卡片：SWOT 与 TOWS 组合

## 它解决什么问题
把企业（或一个业务、一个人）的内部优势、劣势和外部机会、威胁放在一起，找出适合采取的战略方向。

## 什么时候用
- 要做整体的战略盘点，在定方向之前先弄清楚“我们现在处在什么位置”。
- 已经做过 PEST 或五力等外部分析，需要把外部判断和自身能力对接起来。

## 什么时候不用，或换用什么
| 情况 | 换用 |
|---|---|
| 只想看行业值不值得进 | 波特五力 |
| 只想看宏观政策、经济、技术趋势 | PEST |
| 问题是组织内部执行不到位 | 麦肯锡 7S |
| 问题是份额被对手抢走 | 3C |
| 多个业务之间怎么分配资源 | BCG 或 GE 矩阵 |
| 需要把判断量化、比较多个方案 | IFE / EFE 加权打分，再用 QSPM |

## 操作步骤
1. **先定对象和目标**：分析谁（公司、某条业务线、某个产品），为了回答什么决策。
2. **外部先行**：机会和威胁来自外部环境，最好基于 PEST 或五力得出，而不是凭感觉写。
3. **内部对标**：优势和劣势必须是“相对于竞争对手”而言的，没有对比的优势不算优势。
4. **每格只留 3～5 条最关键的**，并写出事实依据。
5. **做 TOWS 组合**（这一步最关键，很多人漏掉）：
   - SO：用优势抓机会（进攻）
   - WO：借机会补劣势（扭转）
   - ST：用优势避威胁（多元化或防守）
   - WT：减少劣势、回避威胁（防御或收缩）
6. **排序**：从组合出的策略中选 2～3 条最重要的，写成行动建议。

## 输出模板
```
分析对象：……　要回答的决策：……

|        | 机会 O（外部）      | 威胁 T（外部）      |
|--------|---------------------|---------------------|
| 优势 S | SO 策略：……         | ST 策略：……         |
| 劣势 W | WO 策略：……         | WT 策略：……         |

S：1. ……（依据：……）
W：1. ……
O：1. ……
T：1. ……

优先建议：1. …… 2. …… 3. ……
```

## 常见误用
- 只列四格清单，不做组合、不排序，得不出任何行动。这是 SWOT 最常见的问题。
- 把内部因素写进机会威胁（比如把“我们有新产品”写成机会）。
- 优劣势不跟对手比，只是自我评价。
- 每格堆十几条，重点被淹没。

## 示例思路
资料《SWOT分析法（37P）》里有京东商城案例。当企业内忧外患、成本状况恶化时，往往只能采用 WT 防御战略，以降低成本为主。

资料：《SWOT分析法（37P）》《SWOT分析模型》《常用的六大管理模型》《麦肯锡咨询工具与方法模型》。补充：公开资料指出 SWOT 主观、不排序、容易过度简化，需要数据支撑和后续排序。
