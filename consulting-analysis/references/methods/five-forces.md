# 方法卡片：波特五力与 SCP

## 它解决什么问题
判断一个行业的竞争强度和盈利潜力：这个行业值不值得做，利润会被谁拿走。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 判断行业吸引力，决定进入或退出 | 五力 |
| 竞争格局正在变化（新进入者、替代品、买方集中） | 五力 |
| 想预测一个外部冲击（新政策、外资进入）会如何改变行业 | SCP（结构—行为—绩效） |

## 什么时候不用
- 技术剧变、边界模糊的行业（五力是静态分析，假设行业结构稳定），需要补充 PEST 和情景规划。
- 问题是企业内部能力，而不是行业结构。

## 操作步骤（五力）
1. **界定行业边界**：哪些产品、哪些地区。边界不同，结论完全不同。
2. **逐一分析五种力量**：
   - 现有竞争者之间的竞争：集中度、增长速度、差异化程度、退出壁垒
   - 新进入者的威胁：规模经济、资本需求、渠道、政策壁垒
   - 替代品的威胁：替代品的性价比、转换成本
   - 供应商的议价能力：供应商集中度、投入品的重要性
   - 买方的议价能力：买方集中度、转换成本、价格敏感度
3. **给每种力量打分**：强、中、弱，并写明依据。
4. **得出结论**：行业整体吸引力如何？哪一种力量最关键？
5. **找应对策略**：企业怎样定位才能避开最强的力量。

SCP：先描述行业结构（集中度、进入壁垒、产品差异），再看企业行为（定价、广告、研发、并购），最后看绩效（盈利、效率）；预测时，分析外部冲击先改变哪一层，再如何传导。

## 输出模板
```
行业边界：……
| 力量 | 强度 | 主要依据 |
|---|---|---|
| 现有竞争 | 强 | …… |
| 新进入者 | 中 | …… |
| 替代品 | …… | …… |
| 供应商议价 | …… | …… |
| 买方议价 | …… | …… |
结论：行业吸引力 ……；最关键的力量是 ……；我们的应对：……
```

## 常见误用
- 行业边界没有定义清楚。
- 只描述，不打分、不下结论。
- 把五力当成企业竞争力分析，其实它分析的是整个行业。
