# 方法卡片：降本（价值链成本分析、零基预算、复杂度削减）

## 它解决什么问题
成本太高、利润被侵蚀，需要找出成本集中在哪里、哪些支出不创造价值。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 想知道成本集中在哪个环节 | 价值链成本分析 |
| 预算年年只增不减，想彻底重审 | 零基预算 |
| 产品、流程、组织层级太多，并购后重叠严重 | 复杂度削减 |

## 什么时候不用
- 成本来自质量问题或流程浪费（返工、等待、库存）：交给 management-toolkit 的精益或六西格玛。
- 公司处在需要投入换增长的阶段，一味降本会伤害竞争力。

## 操作步骤
1. **画出成本地图**：按价值链环节（采购、研发、生产、物流、销售、服务、管理）列出成本和占比。
2. **对标**：每个环节和行业水平或最佳实践比，找出偏高的环节。
3. **零基审视**：对偏高环节的每一项支出问“如果从零开始，我们还会花这笔钱吗？花多少？”
4. **找复杂度来源**：长尾产品、定制化、审批层级、重复的系统和岗位。
5. **分类处理**：取消、减少、合并、外包、自动化。
6. **保护战略投入**：明确哪些支出是战略重点，不在削减之列。

## 输出模板
```
| 环节 | 成本 | 占比 | 行业水平 | 差距 | 可行措施 | 预计节省 |
|---|---|---|---|---|---|---|
战略性投入（不削减）：……
```

## 常见误用
- 平均削减，每个部门砍 10%，结果削弱了关键能力。
- 只看直接成本，忽视复杂度带来的隐性成本。
- 削减后没有机制防止成本反弹。
