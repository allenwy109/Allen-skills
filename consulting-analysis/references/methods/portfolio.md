# 方法卡片：业务组合（BCG 矩阵、GE 矩阵、产品生命周期等）

## 它解决什么问题
企业有多条业务或多个产品时，回答“哪个该投、哪个该收割、哪个该放弃”。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 快速判断各业务的投资优先级，数据有限 | BCG 矩阵（市场增长率 × 相对市场份额） |
| 需要考虑更多因素 | GE 矩阵（行业吸引力 × 业务竞争力，九宫格） |
| 判断一个市场属于哪种状态 | 市场吸引力（果园）矩阵（增长率 × 集中度） |
| 成熟市场中看自己的竞争地位 | 三四规则矩阵 |
| 看各业务单元的盈利与份额 | ROS-RMS 矩阵（销售回报率 × 相对市场份额） |
| 判断单个产品处在哪个阶段 | 产品生命周期（导入、成长、成熟、衰退） |

## 什么时候不用
- 只有一条业务：用利润树、竞争战略等方法。
- 业务之间有强协同（比如引流产品和利润产品），单独评估会误判。

## 操作步骤（BCG）
1. 收集每个业务的销售额、市场增长率，以及最大竞争对手的销售额。
2. 计算相对市场份额 = 本业务收入 ÷ 最大竞争对手收入。
3. 把业务标在矩阵上，气泡大小代表收入：
   - 明星（高增长、高份额）：继续投资，维持领先
   - 金牛（低增长、高份额）：收割现金，支持其他业务
   - 问题（高增长、低份额）：选择性投资，或者放弃
   - 瘦狗（低增长、低份额）：考虑退出，把资源转给明星和问题业务
4. 看组合是否健康：有没有足够的金牛养活明星和问题业务。

GE 矩阵：行业吸引力（市场规模、增长、利润率、竞争强度等）和业务竞争力（份额、品牌、成本、技术等）各分高、中、低，业务落在左上三格就投资发展，对角线三格就选择性维持，右下三格就收割或退出。

## 输出模板
```
| 业务 | 收入 | 市场增长率 | 相对份额 | 象限 | 建议 |
|---|---|---|---|---|---|
组合判断：……
```

## 常见误用
- 机械地“砍掉瘦狗”，忽略它对其他业务的协同作用。
- 市场边界定义不同，份额和增长率完全不同。
- GE 矩阵的打分主观，却当成精确结论（资料指出 GE 矩阵大量依赖主观判断，也没有体现产业发展阶段）。
