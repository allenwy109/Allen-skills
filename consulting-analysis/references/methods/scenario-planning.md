# 方法卡片：情景规划

## 它解决什么问题
未来高度不确定、无法预测时，不去赌一种未来，而是为几种可能的未来都准备好应对策略。

## 什么时候用
- 行业面临重大不确定性（政策方向、技术路线、需求变化），而且决策影响长远。
- 已经识别出 2 个左右最关键、最不确定的驱动因素。

## 什么时候不用
- 不确定性不大，常规预测就够用。
- 决策是短期、可逆的，不值得花大力气做情景。

## 操作步骤
1. **确定焦点问题和时间跨度**：比如“5 年后我们的核心业务会怎样？”
2. **列出驱动因素**：可以借用 PEST 的结果。
3. **按“影响程度 × 不确定性”筛选**：影响大但确定的因素作为所有情景的共同前提；影响大且不确定的因素，挑出最关键的两个。
4. **构建情景**：两个不确定因素各取两个极端，组成 2 × 2 共四个情景，给每个情景起一个好记的名字，描述它会是什么样子。
5. **推演策略**：每个情景下我们应该怎么做？
6. **找出稳健策略**：在所有情景下都有效的做法先做；只在某个情景下有效的做法，设定触发信号，信号出现再做。

## 输出模板
```
焦点问题：……（时间跨度：……）
关键不确定因素：A（……到……），B（……到……）
| | B 高 | B 低 |
|---|---|---|
| A 高 | 情景 1：……  策略：…… | 情景 2：……  策略：…… |
| A 低 | 情景 3：……  策略：…… | 情景 4：……  策略：…… |
稳健策略（现在就做）：……
触发信号与对应动作：……
```

## 常见误用
- 做成“乐观、中性、悲观”三种预测，这不是情景规划。
- 选的两个不确定因素其实高度相关。
- 情景写得很精彩，却没有转化成策略和触发信号。
