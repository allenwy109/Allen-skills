# 方法卡片：组织诊断（麦肯锡 7S、韦斯伯德六盒模型、Burke-Litwin 模型）

## 它解决什么问题
战略执行不下去、组织运转不畅时，诊断问题卡在组织的哪个部分。本卡片只负责“诊断”，诊断之后怎么推动变革，交给 management-toolkit 的变革管理卡片。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 战略执行不到位、并购整合、组织重组，要看各要素是否一致 | 麦肯锡 7S |
| 想快速、让员工参与地做诊断，作为讨论的起点 | 韦斯伯德六盒模型 |
| 要做大的组织变革，需要看清因果和先改哪里 | Burke-Litwin 模型 |

## 什么时候不用
- 问题来自外部市场（需求下降、竞争加剧）：7S 不看外部环境，先用五力或 3C。
- 只是个别团队或个人的问题：用 management-toolkit 的团队管理方法。

## 操作步骤（7S）
1. 逐项描述现状：
   - 硬要素：战略、结构、制度（流程与系统）
   - 软要素：共同价值观（居于中心）、风格（领导方式）、员工、技能
2. 描述理想状态：要实现新战略，每个要素应该是什么样子。
3. 找出不一致：要素之间互相矛盾的地方（比如战略要求创新，但考核制度只奖励不犯错）。
4. 确定优先改变哪几个要素。

六盒模型：目标、结构、关系、奖励、领导、支持机制六个方面，适合用问卷或工作坊让员工参与打分讨论；它的局限是不体现各因素之间的相互影响。

Burke-Litwin：把外部环境、使命与战略、领导、文化这些“变革性因素”和结构、制度、管理实践、氛围这些“交易性因素”分开，先改前者，才能带动后者。

```
| 员工 | | | |

最关键的不一致：……
优先改变：……
```

## 常见误用
- 只看硬要素（改架构、改流程），忽视软要素（文化、领导风格）。
- 七个要素各写一段，没有分析它们之间的矛盾。
- 没有访谈就做诊断，结论流于表面。
