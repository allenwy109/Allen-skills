# 信息卡片

卡片是证据的组织方式：一张卡只装一条信息，按"对主线有多重要"分级，记录它最终去了哪里。卡片存在证据账 `cards.jsonl`（字段见 `<运行时>/tools/lib/schema/ledger.schema.json` 的 cards 表），用 `<运行时>/tools/lib/ledger.py add cards` 登记，`storyline cards` 生成可读的 `02_info_cards.md`。

## 1. 字段怎么写

| 字段 | 写法 |
|---|---|
| id | `card-0001` 起顺序编号，全局唯一、不复用；删掉的卡留空号 |
| type | 12 种：数据、事实、观点、洞察、案例、引语、问题、风险、约束、建议、方法、背景 |
| content | 保留原始数字、单位、时间、口径、主体和限定；关键表述加引号保留原话；不写程度形容词 |
| meaning | "所以呢"：这条信息对主线意味着什么。A、B 级必填，和内容分开写（排主线看含义，核对保真看内容）。含义里的数字不进入事实库 |
| source_refs | 来源 ID + 定位，如 `M003 p12`、`U001 §2.1`、`U001 表2`、`U004 访谈3`；多来源并列 |
| value_tier | A、B、C（见下） |
| topic | 自由标签，同一主题全程用同一个词 |
| claim_id | A、B 级的数据、事实、观点、洞察、风险、建议类卡片必须关联主张 |
| nature、confidence、confidence_reason | 只给没关联主张的卡片填；关联了主张的，由主张推出（下表） |
| period、population、unit、denominator、limitation、metric_refs | 结构化口径，导出报告引擎时直接用 |
| external_supplement | 允许外部知识时的补充，写明来源 |
| placement | 去向（见第 6 节） |

关联了主张的卡片：主张 kind 为 fact、data → 事实；estimate、forecast、judgment、recommendation → 推断；third_party_view → 观点；assumption → 假设。可信度取主张的 confidence。

## 2. 分级

决定性问句：**抽掉这张卡，中心论点或某个关键支撑点会不会立不住、要改口？**

- 会 → A。典型：独有或稀缺的数据、决定性的量化证据、反直觉的洞察、影响决策的风险或约束、关键人物的原话、与主线冲突的少数派证据。
- 不会，但能让论证更可信、更具体 → B。佐证、背景、例证、口径说明、过程数据。
- 都不是 → C。重复、空泛、过时、无关。

校准：A 通常占四分之一到三分之一；卡片 ≥20 张且 A ≥35% 时脚本告警，说明判据用宽了，要重刷。拿不准先判 B，阶段 3 可以升级——漏提取补不回来，分级随时可改。

硬规则：C 级不进交付物，审计时说得出它为什么是 C；少数派证据不低于 B；提取不按价值过滤；阶段 3 复核分级时直接改卡片，并在故事线的复核表里写依据。

## 3. 按材料类型提取

| 材料 | 要做 | 不要 |
|---|---|---|
| 会议纪要 | 区分发言人和立场；保留有分量的原话；记结论、待办、分歧；注意日期和参会层级 | 把个人判断写成公司结论 |
| 访谈 | 标受访者身份和利益关系；区分推测和陈述事实；记下非主流意见 | 把一句抱怨升级成普遍结论 |
| 数据表 | 保留关键行列的原值、列名、单位、口径行和备注行；核对总计与分项 | 丢掉单位和口径；自己四舍五入 |
| 旧 PPT | 只取结论和数据，注明制作时间 | 继承它的结构和标题 |
| 报告 | 优先取数据和结论，记下方法和样本；读到末节和附录 | 照抄叙述顺序 |
| 邮件 | 取承诺、数字、时间节点、分歧，保留发件人角色和日期 | 把口头估算当正式数据 |
| 网页 | 记网址、访问日期、发布方；检查是否截断 | 把片段当完整表述 |

## 4. 去重与冲突

- 同义合并成一张卡，来源全部保留，内容取最精确的表述。相似但口径不同的不合并，那是冲突。
- 冲突先排查假冲突（口径、时间、方法不同）。真冲突登记到证据账的冲突表（双方值、口径、定位、差异原因、处置）。
- 处置三选一：说明原因；并列呈现；采用更权威的一方并写理由。都要有书面记录。
- 行文可以收敛成一句判断，前提是冲突表保留双方原值、正文写明取用理由。禁止取平均或折中。冲突本身可以写进风险或待决问题。

## 5. 术语口径对照与派生卡

- `02_terms.md`：一张表，列为"概念｜材料中的叫法和口径｜采用表述｜说明（相差多少）"。全文统一用采用表述。
- 派生卡（自己算出来的数）：`derived_from` 列出输入卡；关联一条 kind=estimate 的主张，主张的 calculation 写算式，指标用公式指向输入指标，输入卡对应的主张写进 assumptions；可信度取"输入主张中最低者"和"推算精度"中更低的一个，写进主张的 confidence 并说明理由。正文里仍要标"推断"。

## 6. 去向

可选去向：章节、页面、讲者备注、备用页、附录、待定池、确认不用。

- **只认实际交付物**：卡片 ID 出现在 `04_manuscript.md` 正文，或 `06_slides.md` 的正文、可视化建议、讲者备注里，才算安置。只在故事线里出现 = 排了没用上；只在审计里出现 = 只登记没安置；只在逐页的"来源"字段里出现也不算。
- A 级不允许"确认不用"：要么写依据降级，要么承认主线有缺陷。
- B 级进待定池要写原因。
- 验收时还会在成品上再查一遍：A 级卡片关联的主张必须出现在报告正文里。
