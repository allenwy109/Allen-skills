# 审计

先跑 `storyline check <任务> --json`，把完整输出贴进审计报告附录，再走人工清单。原则：先自己修；不把缺失改称"可选"；**脚本通过不等于审计通过**。

## 1. 审计报告（07_audit_report.md）的 10 节

1. **指标摘要**：A 级总数、有去向数、覆盖率；A 级占比；B 级总数、已安置、待定池；脚本错误和警告数；数字回查（核对数、失真数、无法回溯数）；冲突（已处置、待裁决）；缺口（已补、待补）；覆盖风险材料数；跑过的命令。
2. **覆盖审计**：没用上的 A/B 卡逐条列（全部用上也保留表头写"无"）；A 卡去向总表（卡片、一句话内容、实际位置、已核实出现）。
3. **保真回查**：位置、卡片、核对项（数值、单位、时间、口径、限定）、结果；无法回溯的数字表；因果强度和范围词抽查。
4. **结构检查** 10 项：结论先行、以上统下、归类分组、逻辑递进、MECE、SCQA 有效、横向、纵向、一页一信息、页数与时长匹配。每项给结论，不通过写修法。
5. **一致性**：母版与清洁版；母版与逐页的术语、数字、结论；逐页里同一指标的口径。
6. **冲突清单**：编号、指标、双方值与口径、处置、是否进稿。
7. **证据缺口**：缺什么、影响哪个结论、怎么补。
8. **假设清单**：假设、错了会怎样、来源。
9. **待用户确认**：事项、选项、影响、建议（不用开放问题）。
10. **未能修正**：问题、原因、建议。

## 2. 反模式（逐条判定，判定法就是通过标准）

| # | 反模式 | 判定法 |
|---|---|---|
| 1 | 形式化 SCQA | C 段至少有一个具体数字或时点；读完 C 能自然问出 Q；A 是断言并正面回答 Q |
| 2 | 话题式标题 | 标题列表里没有名词短语，每条都含判断或数字 |
| 3 | 平均化摘要 | 每个"提升、下降、增长、改善"后 20 字内有数字 |
| 4 | 为了顺畅丢掉反证或限定 | 冲突条目在稿中都有处理；抽查 5 张带限定的卡，限定仍在 |
| 5 | 一页多结论 | 标题不用"与、及、同时"连接两个结论；正文每条都支撑标题 |
| 6 | 库外数字或事实 | 脚本零 number-unknown 错误；抽查逐页的 5 个数字能回溯 |
| 7 | 只认真处理前几份材料或长文档前部 | 没有"未处理"；写明读到哪；存在页码超过总页数 60% 的来源定位 |
| 8 | 无关材料塞进交付物 | 04、05、06 搜不到无关材料的专有词，且它在卡片库里确实是 C |
| 9 | 去向表写了、正文没有 | 脚本零"只在故事线挂名"；抽查 5 张卡确实在登记的位置 |

## 3. 人工方法

- **结构**：只看首段、章首句、标题；抽一个支撑点，看下层是否超出它；同一章能否一词概括；打乱顺序是否变差；页数 ÷ 时长是否在节奏区间。
- **数字回查 7 步**：抽出所有含数字的句子，标记有无引用 → 没引用的三选一（补卡、加推断标记写依据、删除；日期序号除外；自算的走派生卡）→ 有引用的核对数值、单位、时间、口径、限定五项 → 核因果强度 → 核范围词（试点写成全部？4 个人写成普遍？）→ 反查 A 卡的关键数字是否进了正文 → 对逐页重复以上步骤。

## 4. 各阶段自检

| 阶段 | 自检 |
|---|---|
| 0 | 7 项齐；假设已标；问题不超过 5 个且有默认；上限已定 |
| 1 | 没有未处理；版本已裁定；长文档读到末段；低相关也提了；分批有进度表 |
| 2 | 字段齐，A/B 有含义；编号不重复、跳号有说明；单位口径保留；原话有引号；冲突表和术语表齐；有 A 级清单；少数派不低于 B |
| 3 | 2–3 个有差异的候选；电梯测试；挂卡和强度；有安置；三类质疑有处置；确认点已过；结构树完整 |
| 4 | 章首句、段首句是结论；引用能解析；推断有标记；缺口占位；摘要 200–400 字；建议有优先级；风险、前提、待决分块；清洁版由脚本生成；删词过一遍 |
| 5 | 类型已定；页数在预算内；一页一信息；行动标题；横纵检查；数据页三要素；每页有备注和过渡；备用页够数；结尾合规；没有库外信息；slides.json 已 sync |
| 6 | 脚本零错误；按实际产出回查；逐条列未用的卡；数字和一致性检查完成；冲突和缺口清单完整；未修正项写原因 |

## 5. 脚本查什么（storyline check）

文件齐全（按阶段）；06 必须先有 05；简报 7 项；材料没有未处理、长文档写读到哪、来源 ID 在证据账里；证据账自身的检查（含 A/B 卡缺含义、A 卡关联主张必须影响结论、C 卡不进交付物）；02 视图与证据账一致；A 级占比校准；编号跳号；派生卡格式；故事线有结构树、压力测试、故事线模式；主线确认点；清洁版由母版生成；执行摘要字数和【待补充】；必备章节；数字（带引用句子里的数字必须在事实库里，事实库只取卡片内容和所关联主张的指标；支持负号、量级换算只在两边都写了量级单位时做、‰ 和 bp 等单位、区间不当日期、带引用句子里的小整数也查；判断类标记必须紧挨数字并写依据才降为警告）；删词；行动标题长度；页面类型；结尾页；备用页数；页数上限；slides.json 符合 schema、故事线模式与 arc 一致、与 06 同步；悬空引用；C 卡出现在交付物；A/B 卡去向。
