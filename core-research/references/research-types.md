# 研究类型、开题与报告结构

## 1. 七类研究

混合类型时，以主决策定类型，另一类的骨架作为补充维度，不并列开两条无关的主线。子问题按"对决策的影响 × 当前不确定性"排优先级（P0、P1…），尽量 MECE，3–7 个，每个写明需要什么证据。

| 类型 | 核心交付 | 子问题骨架 |
|---|---|---|
| 全景 | 格局 → 驱动 → 产业链 → 趋势 | 规模、增速和口径，各统计机构差多少；参与者分类和各自的立足点；价值在哪段产生、被谁拿走；驱动和抑制因素；技术、政策、需求侧的拐点信号；1–3 年可验证的情景和观测指标 |
| 对比选型 | 维度 + 矩阵 + 分场景结论 | 要支撑什么动作（上生产、试点、淘汰）；维度和权重由谁定（用户约束 > 通用榜单 > 供应商话术）；各候选的实测或一手证据；隐藏成本（迁移、运维、锁定、合规、退出）；分场景结论；哪些维度证据不足、需要用户自测 |
| 技术深潜 | 机制 → 证据 → 边界 | 机制和关键假设；有效和失效的边界；计算、经济、组织代价的量级和口径；与替代方案对比；独立复现、基准、失败案例；前沿和未解问题 |
| 尽调 | 业务事实 + 风险信号 | 做什么、靠什么赚钱、现金流从哪来；注册、股权、财务、诉讼、监管记录；管理层公开言论与实际成绩是否一致；客户、供应商、离职员工的说法是否互相印证；风险信号（关联交易、频繁换审计、诉讼、口碑、竞对评价）；什么新证据会推翻判断 |
| 文献综述 | 共识 / 争议 / 空白 | 研究问题、理论脉络、代表作；被多个独立团队验证的共识；争议点及原因（数据、方法、定义、立场）；研究空白；方法学问题（样本、测量、外推）；近 2–3 年的增量 |
| 政策法规 | 条文 + 生效时间 + 影响 + 待专业人士确认 | 原文、关键定义、适用范围；生效时间、过渡期、溯及力；对目标对象的义务、成本、机会；执法口径和已知案例；与既有法规的冲突、替代、补充；要向律师、会计师、监管确认的问题 |
| 事实核查 | 评级 + 证据链 | 精确表述和可证伪的版本；最早出处，以及传播中被改写了什么；支持证据是一手还是转引、有几个独立来源；反面证据和已知反驳；时间、范围、分母、单位是否被偷换；评级（真 / 大致真 / 存疑 / 大致假 / 假 / 无法判定） |

对公司做完整尽调时用 core-diligence；这里的"尽调"类只是事实收集。

## 2. 澄清问题（每个都有默认值）

| 问什么 | 默认值 |
|---|---|
| 用途与决策 | 支撑一次内部方案讨论，不是最终决策 |
| 受众 | 熟悉业务、但不熟悉该领域的同事 |
| 时间范围 | 近 3 年，重点近 12 个月 |
| 地域、细分 | 中国大陆为主，海外作对照 |
| 包含与排除 | 只研究直接影响决策的环节 |
| 已知信息与已有倾向 | 从用户材料起步，不预设结论 |
| 交付形式与篇幅 | 报告正文 3000–6000 字，L3 另交研究包 |
| 信源偏好与禁区 | 公开可得，不用无法存档的付费内容 |
| 时限 | 一次会话内完成 L2 |
| 内部资料能否入包 | 可以，标为内部，对外前删除 |

不能提问时，假设写进简报，并在报告「方法与局限」里逐条复述。

好的开题：每个子问题都可证伪，并标了影响、不确定性、优先级和所需证据的形态。坏的开题：子问题只是一份目录。

## 3. 报告结构

每类都要有：执行摘要、分歧与不确定性、未解问题、方法与局限、参考来源。

| 类型 | 正文顺序 |
|---|---|
| 全景 | 范围口径 → 格局对比表 → 驱动与抑制 → 产业链与价值分配 → 趋势与可验证情景 → 启示 |
| 对比选型 | 执行摘要写"结论 + 适用条件" → 场景约束 → 维度与权重（说明维度来源）→ 对比矩阵（每格写证据和出处）→ 分场景结论 → 隐藏成本与退出风险 → 证据不足、需自测的维度 |
| 技术深潜 | 执行摘要写机制判断和成熟度 → 机制 → 有效边界 → 代价（带口径）→ 替代对比 → 可复现性与失败案例 → 前沿 |
| 尽调 | 执行摘要写可信度和主要风险 → 事实底稿 → 业务与现金流 → 言行对照 → 多方印证 → 风险信号清单（每条：信号 → 来源 → 严重度 → 还需查什么） |
| 文献综述 | 执行摘要用三句话讲共识、争议、空白 → 检索范围（数据库、关键词、时间窗）→ 理论脉络 → 共识 → 争议 → 空白 → 方法学问题 |
| 政策法规 | 执行摘要写影响和时间点 → 条文要点（引原文）→ 生效、过渡期、溯及力 → 义务、成本、机会 → 执法口径与案例 → 与既有法规的关系 → 需向专业人士确认的问题 |
| 事实核查 | 评级加一句依据放最前 → 精确主张 → 证据链（最早出处 → 改写 → 支持 → 反面）→ 口径核对 → 什么证据会改变评级 |

**分歧**：每处交代谁持什么观点（带引用）、为什么不同、你的判断和依据、什么证据会改变判断。不硬凑折中。

**置信度**（写进主张的 confidence）：

- 高：一手来源或 ≥2 个独立可靠来源，口径清晰，没有有力反证；
- 中：证据可靠但单一，或口径有局限，或有小分歧未裁决；
- 低：间接证据、二手转述、样本小、反证未排除。

**参考来源**节的条目格式（检查脚本按这个解析）：

`- [n] 作者或机构. 标题. 发布日期或 unknown. 网址. 访问 日期. 来源 ID \`M001\` 存档 [M001-slug.md](../03_evidence/raw/sources/M001-slug.md)`

编号连续；正文引用写 `[1]`、`[1,3]`、`[1-3]`；年份写法 `[2024]` 不算引用。
