# 检索策略

## 每轮顺序

短宽 → 术语 → 精确 → 反面：

1. **短宽**：2–5 个词找"地图"（综述、行业报告、官方概览）。跳过这一步是漏维度的头号原因。
2. **术语**：从地图里提取术语、机构名、产品名、标准号、英文原名。
3. **精确**：加年份、site:、文件类型。
4. **反面**：问题、争议、失败、局限、批评；vs 替代方案；被高估、被证伪、后来怎么了；事故、召回、处罚、破产；site: 负面信源。

## 每个子问题至少 3 种表述

从 5 个方向变换：中英对照；行业黑话与正式名称；角度（优势、劣势、替代、失败案例、争议）；主体（厂商说法、用户抱怨、第三方评测、监管通报）；时间（加年份或"最新"；查历史时反向加年份）。

## 多语种

- 至少中英各一轮。技术、金融、医药领域英文一手来源更全；政策、市场数据中文更贴近实际。
- 中文：官方文件用"全称 + 文号"；注意出货量、销量、激活量的区别，出厂价还是零售价。
- 英文：注意美式、英式拼写和缩写全称。
- 小语种市场：用英文检索，再用官方原文核对。

## 一手出处在哪

| 事实类型 | 一手出处 |
|---|---|
| 产品、API、价格 | 官方文档、定价页、发行说明 |
| 公司经营、财务 | 财报、年报、监管披露、招股书 |
| 政策 | 公报、条文原文、官方解读、答记者问 |
| 学术 | 论文原文（含补充材料）、预印本、数据集 |
| 市场 | 统计局、行业协会、原始调查报告 |
| 人物观点 | 采访原文、演讲实录、财报电话会 |
| 技术参数 | 规格书、基准脚本、可复现实验 |

**追溯**：在二手文章里找脚注、链接、引号内的原话、报告名，再直接检索原始对象。

## 来源评级

层级（tier）按"事实从哪来"判定，不按载体形式（引用财报页码的博客，就这条事实而言接近一手）：一手可以支撑关键结论；二手用于线索、印证、背景；三手（百科、聚合站、软文、内容农场、榜单）只用来找词和线索。等级（grade）的含义和判据见 `../core-evidence/references/source-tiers.md`；等级评的是材料本身，不是观点——低等级来源里的事实也可能对，只是不能单独承担关键结论。

每个来源必查 4 项：作者与机构（含利益立场）、发布日期、利益冲突（写进 conflict_of_interest 并在报告披露）、方法与样本。

**数字口径 4 项**：统计对象（出货、销量、激活、付费、月活）；单位（币种、是否含税、量级）；时间点（财年还是自然年、期末值还是平均值、汇率取哪天）；统计方法（抽样还是全量、覆盖范围、是否修订过）。口径不同的数字不能直接比较或相除；必须比较时写明换算假设，换算过程放进 analysis/。

## 冲突处理

1. 先比较口径、时间、方法——多数"冲突"其实是这三者不同；
2. 优先采用一手、更新、方法披露更完整的来源；
3. 在证据账冲突表写下裁决理由和未采用的原因，不能只改正文数值而丢掉另一方；
4. 无法裁决的，在「分歧与不确定性」并列呈现，写明判断、理由和置信度；
5. 冲突本身就是发现，值得单独追一轮。
