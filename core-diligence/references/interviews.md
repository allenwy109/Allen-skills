# 访谈与资料请求

## 1. 访谈

- 问题围绕关键问题和能区分解释的开放缺口；不为凑人数而访谈；默认只交提纲（模板 `assets/templates/interview-outline.md`，状态 planned）。不虚构访谈。
- 六类角色：
  - 创始人或管理层：战略为何这样选、怎么执行、哪些结果偏离预期；用决议、预算与实际的差异验证，自述需要其他角色佐证。
  - 财务：收入到回款的差异、受限资金、到期债务安排；用明细账、附注、授权的银行和税务资料验证。
  - 客户：选择、续用、拒绝、流失的原因，试点转付费、验收、替代品；覆盖新老客户、流失和未成交的样本。
  - 供应商：需求预测、结算、质量、产能替代记录。
  - 前员工：只问其任职期间和职责范围内的事，不要求带出保密文件。
  - 行业专家：市场口径和关键假设是否成立、可能推翻判断的反例；注意利益关系。
- 抽样：说明总体、观察期、名单来源和选样方；检查管理层筛选、幸存者偏差、不回应偏差。不设固定人数或机械的正反配额。
- 每次访谈记录：状态（planned / completed）、日期、角色类别、知情范围、利益关系、匿名约定、获准保存的范围、问题、要点、与其他证据是否一致、后续核验。

## 2. 资料请求清单

模板 `assets/templates/request-list.md`。列：优先级、文件或字段、主体与期间、用途和关联缺口、可接受的替代、敏感性与权限、责任角色和完成标准。

- P0：工商、章程、股权原件；财报、附注、债务担保、受限资金；最新研报全文及授权。
- P1：客户和供应商合同、订单验收回款及流失线索；融资治理、诉讼、重要合同；人员、技术与知识产权、数据许可、运营交付；子公司与集团往来、抵销、资金归集。
- P2：非关键补充。

发送前要用户授权。
