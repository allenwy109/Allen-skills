# 行业适配（8 类，可以组合；只是起点，不是上限）

| 行业 | 重点指标与检查 | 首选证据 | 常见误判 |
|---|---|---|---|
| 软件、SaaS、AI | ARR 到收入的桥接；GRR、NRR 按同一队列；CAC 回收用毛利算；推理和算力单价、模型依赖、数据权利、评测、SLA | 合同、订阅队列、账单、成本明细、许可、可复核评测 | ARR 不是收入；LTV 需要稳定的流失假设；演示不等于生产可靠；分清模型自研还是集成 |
| 制造、硬件 | 产能、产出、良率、利用率、采购周期、库存、保修退货、关键设备、扩产 | 生产台账、BOM、质检、订单验收、设备权属、现场授权记录 | 设计产能不等于有效产能；出货不等于收入；爬坡期和长期低效分开 |
| 消费、平台 | GMV 与佣金或自营净额、退货、复购、渠道费、补贴、获客队列 | 交易结算、退货、商家和用户队列、总额净额政策 | GMV 不是净收入；下载和流量不是付费用户；补贴驱动的增长要检验持续性 |
| 金融 | 银行、保险、资管、支付分别看监管资本、流动性、资产质量、期限错配、赔付、AUM 费率；利率、信用、赎回暴露怎样影响收益和资本约束 | 监管披露、审计附注、持牌范围、风险暴露 | 不套一般企业的流动比率或跑道阈值；要行业专业复核；存款不是营收 |
| 医药、医疗 | 注册和临床阶段、试验设计和终点、审批、知识产权、医保支付、商业化、生产质量 | 注册机关、试验登记和论文原文、授权合同、财报 | 获批、可报销、已上市销售是三件事；阶段成功率不能无依据套用；医疗判断需专业人员 |
| 项目制服务 | 在手订单、履约义务、完工进度、验收、应收和合同资产、人员利用率、项目毛利；拆分获客、交付、回款周期 | 项目合同、工时、里程碑、验收回款、收入确认政策 | 中标不等于签约或收入；毛利受跨期估计影响；项目负荷不等于人数 |
| 资源、周期品 | 有效供给、成本曲线、价格和价差、库存、投产和退出、品位和资源寿命、维持性资本开支 | 产销、储量、成本披露、行业库存价格、开发和环保许可 | 周期高点的利润不可持续；储量、产能、可销售产量分开 |
| 重资产、基础设施 | 建设和爬坡、利用率、维持和扩张投入、特许权和收费机制、合同期限、融资结构 | 工程和运营记录、资产权利、收费和采购合同、债务期限、资本开支 | 规划投资不等于已投产；会计利润不等于可分配现金；受监管回报和合同保底要核实条件 |

跨行业的共同规则：

- 只追踪有实际暴露的利率、汇率、原料、能源、政策变量，说明传导、滞后和合同缓释。
- 成熟期看效率和再投资，扩张期看产能和资金是否匹配，早期看需求和单位经济验证；不用融资轮次代替业务阶段。
- 没有对应的专业能力时，写明哪些结论无法形成、还需要什么材料和专家；不能把通用脚本的输出当成行业模型的结论。
