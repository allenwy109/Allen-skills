# 来源与基础阅读

## 1. 来源目录

每个项目启动时重新核验可用性（下表的状态只是构建时的记录），不虚构深层网址。每个来源按运营方、地域、适用事实、入口和查询方式、更新频率、权限费用和局限、回溯原件、最后核验来记。

**中国大陆、香港、澳门**

| 类别 | 平台或机构 | 适用资料 | 局限 |
|---|---|---|---|
| 登记 | 国家企业信用信息公示系统 | 登记、年报、异常 | 申报不等于核验，不含完整受益所有权 |
| 信用 | 信用中国、地方市场监管 | 行政公示 | 不等于完整征信 |
| 聚合 | 企查查、天眼查、启信宝、爱企查 | 工商、司法、股权线索 | 滞后、同名、付费；必须回溯原件 |
| 司法 | 中国裁判文书网、中国执行信息公开网、法院公告 | 案件、执行 | 不公开、撤下、仲裁保密 |
| 交易所与监管 | 上交所、深交所、北交所、全国股转系统、证监会 | 定期报告、公告、招股书、问询、挂牌 | 挂牌不等于上市 |
| 披露 | 巨潮资讯、港交所披露易 | 法定披露原件、发行人公告 | — |
| 债务 | 债券披露平台、募集说明书、评级机构 | 债务条款、担保、评级 | 评级是观点，注意发行人付费关系 |
| 主管机关 | 税务、市场监管、生态环境、海关、网信、工信 | 处罚、许可、政策 | 纳税资料不公开，不能用信用等级推收入 |
| 知识产权 | 国家知识产权局 | 专利、商标 | — |
| 许可认证 | 版权、行业许可证、认证查询 | 主体、范围、有效期 | 证书图片需核真 |
| 采购 | 中国政府采购网、招标投标公共服务、地方公共资源交易 | 采购和中标 | 中标不等于收入或回款；公告、结果、合同、履约分开 |
| 研报 | 券商研究所、商业终端 | 研究和数据 | 需授权 |
| 研报平台 | 公开研报平台 | 发现和摘要 | 上传日不是发布日，转载不等于合法全文 |
| 统计 | 统计机关、行业协会、研究机构 | 原始统计 | 协会样本可能不覆盖总体 |
| 融资 | 企业和投资方公告、融资数据库 | 融资并购线索 | 宣布、签约、完成、变更、到账不同 |
| 经营线索 | 招聘、应用商店、流量、代码仓库 | 产品、技术线索 | 流量不是收入，招聘不是员工数 |
| 舆情 | 媒体、投诉、社交、员工评价 | 争议线索 | 偏差大，不能凭单条定性 |
| 港澳登记 | 香港公司注册处、澳门商业登记 | 法定主体 | 部分付费；交易所公告不等于公司登记 |

**海外**：证券披露（SEC EDGAR 的 10-K、10-Q、8-K、20-F、6-K、S-1、F-1）；公司登记（美国各州、Companies House、ACRA 等）；司法（PACER 及当地法院、CourtListener）；各辖区官方制裁和出口管制系统（聚合命中只是线索）；知识产权（USPTO、EPO、WIPO；专利搜索引擎需回原机关确认）；融资数据库（不等于到账证明）；金融终端；官方统计与国际组织；行业研究机构（摘要不等于全文，不同口径不能相加）；人员与评价平台；产品与流量平台；主流财经媒体（付费，不能只凭媒体品牌采信）。

## 2. 来源策略

- 顺序：官方或授权原件 → 专业研究和方法透明的统计 → 有归属的媒体和自述 → 匿名线索。
- 用户提供的合同或审计报表按真实性评级，不统一降级为宣传。
- 关键词按主体和别名、业务场景、问题、地域语言、来源、时间组合，不机械展开全部组合；正证、反证、澄清、当前状态一起查；名称无结果时换别名和权威路径。
- 各类资料的更新机制不同，不设统一有效期。
- 工具或访问失败时记录：渠道、时间、查询、错误、已试的替代、剩余限制。

## 3. 官网基础阅读（所有目标都做，不因模块裁剪而消失）

- 先确认官网归属：依据可以是用户提供的入口、登记披露里的链接、App 发行方信息、可靠的双向关联；不凭同名、搜索排名或站点自称确认，也不猜域名或 /about 路径。
- 确认后逐项判断 8 类页面是否存在、能否读取：about、products_pricing、founders_team、history_news、locations_channels、investor_relations、terms_identity、visual_assets。
- 每页记录：实际网址、标题、真实性及依据、发布日、信息适用期、访问日、可访问程度、定位。动态或付费内容如实标注；离线时只分析已有存档。存档用 core-research 的 `research capture`。

## 4. 真实视觉素材

记录来源页、原图地址、权利人或授权依据、允许的用途、素材日期、对象和地区、署名、裁切范围。公开可见不等于可以随意复制再发布；不能生成假 Logo、人物、产品或门店图。图片放 `03d_diligence/materials/images/`，规则见 report-content.md。
