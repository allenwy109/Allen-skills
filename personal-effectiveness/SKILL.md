# 个人效率方法工具箱

这套 skill 帮一个人管好自己。和企业咨询、企业管理不同，个人方法的成败几乎完全取决于**能不能坚持下去**，所以选方法时看两件事：
1. **对症**：先搞清楚真正卡住的是什么。“事情做不完”可能是优先级问题，也可能是拖延问题，还可能是精力问题，对应的方法完全不同。
2. **轻量**：优先推荐今天就能开始、只需要一张纸或一个计时器的方法。复杂的系统（比如完整的 GTD）只推荐给已经有一定基础、确实需要的人。

## 和另外两个 skill 的分工

- consulting-analysis：诊断一家企业或一项业务。
- management-toolkit：管理团队和组织。
- 本 skill：管理自己。同一个方法可能在不同 skill 里出现（比如 SMART 既能给团队定目标，也能给自己定目标），这里只讲个人用法。

## 工作流程

### 第一层：找到真正卡住的地方，拆成子问题

先问清楚（或从用户的描述中判断）：
- 症状是什么：做不完、不想做、做不好、坚持不了、想不清楚、学不会、状态差、没方向？
- 持续多久了？偶尔一次还是长期如此？
- 已经试过什么方法，为什么没坚持下来？

信息不够就问一两个关键问题。如果要先给出初步建议，就在回答**开头**写明你对这个人情况的假设（比如“我假设客户的事大多能等几小时”），并说明假设不成立时建议会怎样变化，而不是放在结尾顺带一提。

#### 拆成子问题

用户的一段话里常常不止一个问题。先把它拆成子问题，用 MECE 检查是否不重不漏，并写清三件事：
- 每个子问题是什么（一句话）。
- 子问题之间的关系：并列、有先后（A 定了才能做 B），还是有因果（A 是 B 的原因）。
- 每个子问题属于哪个领域：企业方向（consulting-analysis）、内部管理（management-toolkit），还是个人（personal-effectiveness）。

只有一个子问题时，直接进入下一层，不要为了拆而拆。

### 第二层：给每个子问题选方法

不限定方法的数量，而是按子问题配方法，遵守两条对应规则：
- **每个子问题至少要有一个方法来回答。** 不能有子问题被略过，或者只在结尾带一句。
- **每个方法都必须对应一个具体的子问题。** 说不出它在回答哪个子问题的方法，就不要用。

同一个子问题需要多个方法时可以组合使用（比如先用鱼骨图铺开原因，再用 5WHY 深挖），但要说明为什么组合。每个方法都要说明为什么选它、为什么不用相邻的那个。

子问题属于其他领域时，去读那个 skill 的选法表和方法卡片（它们安装在本 skill 旁边的 `../<skill 名>/` 目录），用那边的方法来回答。

**A. 时间与优先级**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 事情太多，不知道先做哪个 | 四象限（重要 × 紧急） | 事情都很重要、分不出来时，用 80/20 找出最关键的少数 |
| 每天忙忙碌碌，重要的事却没进展 | 80/20 + 要事第一 | 每天早上先做最重要的那件事 |
| 待办清单越列越长，看着就焦虑 | 1-3-5 法则（每天 1 件大事、3 件中事、5 件小事） | 事情来源多、容易遗漏时，用 GTD |
| 事情多、来源杂，脑子里装不下 | GTD（收集、理清、组织、回顾、执行） | GTD 比较重，只想先轻量试试就用 1-3-5 |
| 事情排得满，但总被打断 | 时间块（给不同类型的事固定时段） | 每个时段内部再用番茄工作法 |
| 不知道时间都花到哪里去了 | 时间日志 | 连续记录一周再分析；想长期坚持可以用五项管理行动日记 |

**B. 拖延与专注**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 一想到某件事就不想开始 | 吃青蛙（早上先做最难、最抗拒的那件） | 任务太大无从下手时，先拆成第一个 5 分钟就能完成的小步骤 |
| 注意力坚持不了多久，容易分心 | 番茄工作法（25 分钟专注 + 5 分钟休息） | 需要长时间深度工作的人，可以把番茄钟延长到 50 分钟 |
| 小事堆积 | 两分钟法则（两分钟内能做完的立即做） | 这是 GTD 的一部分 |

**C. 目标与习惯**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 目标太模糊 | 个人 SMART | 长期目标用个人 OKR 分解到季度 |
| 目标定了总坚持不下去 | WOOP（愿望、结果、障碍、计划） | 障碍主要是习惯时，用习惯回路 |
| 想养成或戒掉一个习惯 | 习惯回路（提示、渴望、反应、奖励） | 一次只改一个习惯 |
| 想系统提升个人效能 | 高效能人士的七个习惯 | 这是价值观和原则层面的，不能代替具体方法 |

**D. 思考与决策**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 重大决定拿不定主意（换工作、搬家） | 加权决策矩阵 | 选项的得分接近时，再用 10/10/10 看长远影响 |
| 容易冲动决定，事后后悔 | 10/10/10 法则 | 怕决定出问题时，用事前验尸 |
| 计划看起来很好，担心出岔子 | 事前验尸（假设已经失败，倒推原因） | 适合开始一个重要计划之前 |
| 想弄清楚一件事的本质 | 黄金圈（为什么 → 怎么做 → 做什么） | 需要突破惯性思维时用第一性原理 |
| 想从更多角度看问题 | 多元思维模型、逆向思维、二阶思维 | 适合平时训练思维，不是马上能用的工具 |

**E. 学习**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 以为懂了，一讲就讲不清 | 费曼技巧（讲给外行听） | 适合理解概念，不适合练技能 |
| 想提升某项技能，练了很久没进步 | 刻意练习（在学习区练、及时反馈、针对性纠正） | 需要有人或有办法给反馈 |
| 学过就忘 | 间隔重复（按遗忘曲线复习） | 适合需要记住的知识，如语言、考试 |
| 听课、开会记的笔记没用 | 康奈尔笔记（记录栏、提示栏、总结栏） | 想把书读成可用的东西时用 RIA |
| 读了很多书，用不起来 | RIA 阅读法（读原文、复述、联系经验、规划应用） | 只想快速了解一本书，用思维导图梳理结构 |
| 想理清一个主题的全貌 | 思维导图 | 需要严格的逻辑结构时，用金字塔原理 |
| 不知道怎么学最有效 | 学习金字塔（主动学习的留存率远高于被动学习） | 只是一个原则，要落到费曼或刻意练习 |

**F. 情绪、压力与精力**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 被某件事搞得情绪很差 | 情绪 ABC（事件、信念、结果：改变看法） | 长期压力大时，用压力管理的方法 |
| 压力大，担心最坏的结果 | 凯利魔术方程式（设想最坏情况 → 接受它 → 设法改善）/ 3R 减压（放松、退缩、重整） | 如果影响到睡眠和身体，应当建议寻求专业帮助 |
| 下午就没精神，效率很低 | 精力管理（体能、情绪、思维、意义四个层面） | 配合时间块，把重要工作放在精力最好的时段 |

**G. 自我认知与职业发展**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 不清楚自己的优势和短板 | 个人 SWOT | 想看更深层的动机和价值观时用冰山模型 |
| 想看清别人眼中的自己 | 乔哈里视窗（主动寻求反馈，缩小盲区） | 需要有信任的人愿意给真实反馈 |
| 职业方向迷茫 | 剥洋葱法（从长期理想逐层剥到当下该做的事）+ 职业规划六步 | 先想清楚个人愿景和使命 |
| 从员工走向管理岗，不知道该补什么 | 领导梯队（每个阶段的工作重点不同） | 与 management-toolkit 的领导力方法配合 |

**H. 个人表达**
| 症状 | 首选 | 何时换用 |
|---|---|---|
| 面试、述职讲不清自己的经历 | STAR（情境、任务、行动、结果） | 汇报工作结论用 SCQA（见 consulting-analysis） |
| 别人跟我说话时总觉得我没在听 | SOFEN 倾听（微笑、开放姿态、前倾、眼神交流、点头） | 关系紧张时用非暴力沟通 |
| 一说话就容易吵起来 | 非暴力沟通（观察、感受、需要、请求） | 对事不对人 |

### 第三层：按卡片做分析

**选定方法后，先读对应的方法卡片再作答。** 在 `references/method-index.md` 末尾（个人方法在表格的“卡片”一列）找到对应的卡片文件，打开 `references/methods/` 下的这张卡片，把其中的操作步骤、输出模板和“常见误用”用进回答。选法表只告诉你用哪个方法，怎么用对要看卡片。

### 第四层：综合成可落地的方案

方法只是中间过程，用户要的是一个能执行的方案，而不是几份各自独立的框架分析。把各个子问题的结论合在一起，做四件事：
1. **理清关系**：结论之间有没有冲突（比如一个要求聚焦，另一个要求扩张）？有没有依赖（一个结论是另一个的前提）？有冲突就做取舍，并说明理由。
2. **排出先后**：按依赖关系和影响大小，排出先做什么、后做什么。
3. **对照资源**：人手、时间、预算够不够？不够就砍掉或推后优先级低的动作。
4. **检验能否落地**：每个动作都要有负责人、时间和衡量标准。再做一次事前验尸：“如果三个月后这个方案失败了，最可能是因为什么？”把答案变成预防措施。

只有一个子问题时，综合就是把分析结论转成行动，并做第 3、4 项检查。

个人方案还要多守一条：**一次只改一件事**。有多个子问题时，综合的结果不是同时上几套方法，而是排出先后：先上最关键的一个，稳定一到两周后再加下一个。

#### 输出格式

个人方法最怕“听起来都对，就是做不到”。所以输出要做到：
- **第一步足够小**：今天、甚至现在 5 分钟之内就能开始做。
- **给出具体模板**：比如画好的四象限表、今天的 1-3-5 清单、WOOP 的四个问题。
- **说明怎么判断有效**：试用一到两周，看什么信号说明方法起作用了。
- **说明坚持不下去怎么办**：最常见的放弃原因和对策。

最后附方法说明：每个子问题用了什么方法、为什么适合这个人、为什么没推荐相邻的那个。

## 几条底线

- 先对症，再开方。不要一上来就推荐一整套系统。
- 不要套方法：方法是为回答子问题服务的，最终交付的是一个能执行的个人计划。
- 一次只改一件事。同时上三个新方法，通常三个都坚持不下来。
- 尊重个人差异：有人适合早起吃青蛙，有人夜里效率最高，方法要贴合这个人。
- 如果用户描述的情绪或压力已经严重影响睡眠、健康或正常生活，要温和地建议寻求专业帮助，而不是只给效率技巧。
