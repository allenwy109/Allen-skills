# 方法卡片：习惯回路

## 它解决什么问题
想养成一个好习惯，或戒掉一个坏习惯。习惯由“提示、渴望、反应、奖励”四个环节组成，改变习惯就是改造这四个环节。

## 什么时候用
- 想养成每天运动、阅读、早睡等习惯。
- 想戒掉刷手机、熬夜、拖延等坏习惯。

## 什么时候不用
- 问题不是习惯，而是目标不清：先用个人 SMART。
- 一次想改很多习惯：先只选一个。

## 四个环节
1. **提示**：触发行为的信号（时间、地点、情绪、之前做的事）。
2. **渴望**：想得到的感觉或状态。
3. **反应**：实际的行为。
4. **奖励**：行为带来的满足感。

## 操作步骤
**养成好习惯**
1. 让提示显而易见：把跑鞋放在门口，把书放在枕头边。
2. 让它有吸引力：和喜欢的事绑在一起（跑步时听喜欢的播客）。
3. 让它简单易行：从两分钟版本开始（先读一页书）。
4. 让它令人满足：记录打卡，给自己小奖励。
5. 用习惯叠加：“在做完（已有习惯）之后，我就（新习惯）。”

**戒掉坏习惯**：反过来做——让提示看不见（手机放在另一个房间），让它没吸引力，让它难以做到，让它令人不满足。

## 输出模板
```
目标习惯：……
提示：……
两分钟版本：……
习惯叠加：在 …… 之后，我就 ……
奖励和记录方式：……
```

## 常见误用
- 一开始就定很高的标准（每天跑 5 公里），很快放弃。
- 只靠意志力，不改变环境。
- 断了一天就彻底放弃；正确的做法是不连续断两天。
