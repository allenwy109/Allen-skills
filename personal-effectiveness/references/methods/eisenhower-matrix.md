# 方法卡片：四象限与 ABC 控制法

## 它解决什么问题
事情太多，分不清先做哪个，结果总在救火，重要的事一拖再拖。

## 什么时候用
- 每天或每周排优先级。
- 感觉一直很忙，但重要的事没有进展。

## 什么时候不用，或换用什么
- 所有事都“重要又紧急”，分不出来：用 80/20 找出最关键的那一两件。
- 问题不是分不清先后，而是不想开始：用吃青蛙或番茄工作法。

## 四个象限
| | 紧急 | 不紧急 |
|---|---|---|
| 重要 | 第一象限：马上做（危机、截止日期） | 第二象限：安排时间做（规划、学习、关系、预防） |
| 不重要 | 第三象限：尽量委托或简化（打断、部分会议） | 第四象限：少做或不做（消遣、无意义的琐事） |

关键在第二象限：重要但不紧急的事最容易被挤掉，而它恰恰决定长期结果。第二象限做得好，第一象限的危机就会变少。

## ABC 控制法
把事情分成 A（必须做、最重要）、B（应该做）、C（可以做）三类，先做完 A 再做 B，C 能不做就不做。它是四象限的简化版，适合快速排当天的任务。

## 操作步骤
1. 把所有待办事项写下来。
2. 逐一判断：重要吗（是否影响我的长期目标）？紧急吗（是否有迫近的截止时间）？
3. 放进四个象限。
4. 给第二象限的事预留固定时间（比如每天早上一小时）。
5. 第三象限的事想办法委托、合并处理或拒绝。
6. 每周回看一次，看时间是否越来越多地花在第二象限。

## 输出模板
```
| 重要且紧急 | 重要不紧急（预留时间：……） |
| 紧急不重要（委托给：……） | 不重要不紧急（不做） |
```

## 常见误用
- 把“别人觉得紧急”的事当成“对我重要”。
- 画完象限还是先做紧急的小事。
- 第二象限没有具体时间安排，只停留在清单上。
