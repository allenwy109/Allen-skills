# 方法卡片：加权决策矩阵

## 它解决什么问题
面对几个选项（换哪份工作、买哪套房、选哪个供应商）犹豫不决时，把判断标准和权重摆出来，让选择更理性。

## 什么时候用
- 有 2 到 5 个明确的选项，涉及多个考虑因素。
- 个人重大决定，或者需要向别人解释为什么这样选。

## 什么时候不用
- 选项之间差别很大，一眼就能看出来。
- 决定的关键在于长期影响或风险：配合 10/10/10 或事前验尸。

## 操作步骤
1. 列出所有选项。
2. 列出判断标准（比如收入、成长空间、通勤时间、工作稳定性）。
3. 给每个标准一个权重（总和为 100%），反映它对你有多重要。
4. 给每个选项在每个标准上打分（1 到 5 分）。
5. 权重 × 分数，加总。
6. 检查结果：如果总分最高的选项让你心里不舒服，说明有某个标准或权重没写出来，补上后重算。

## 输出模板
```
| 标准 | 权重 | 选项 A | 选项 B | 选项 C |
|---|---|---|---|---|
| 收入 | 30% | 4（1.2） | 3（0.9） | 5（1.5） |
| …… | | | | |
| 合计 | 100% | …… | …… | …… |
直觉检查：……
```

## 常见误用
- 先有了想要的答案，再调权重去凑。
- 把分数当成精确结果：总分接近时，应该再用其他方法判断。
- 标准之间重复计算（“薪资”和“收入”是同一个东西）。
