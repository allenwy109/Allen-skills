# 方法卡片：时间块与番茄工作法

## 它解决什么问题
- 时间块：总被打断，一天被切得支离破碎。
- 番茄工作法：注意力坚持不了多久，容易分心。

## 什么时候用
| 症状 | 用哪个 |
|---|---|
| 工作总被会议、消息打断，没有整块时间 | 时间块 |
| 坐下来没多久就想看手机 | 番茄工作法 |
| 两个问题都有 | 用时间块安排一天，在每个深度工作块里用番茄钟 |

## 什么时候不用
- 工作本身就是随时响应（比如客服、值班）：只能在空档里安排小块时间。
- 已经进入心流状态：番茄钟响了也不必强行打断，可以延长。

## 时间块操作步骤
1. 把一天分成几个时间块，每块专门做一类事：深度工作、会议、邮件和消息、杂事、休息。
2. 把最重要的深度工作放在自己精力最好的时段。
3. 在日历上标出来，像对待会议一样保护它。
4. 邮件和消息集中在固定时段处理，比如上午 11 点和下午 4 点。
5. 每天结束时回顾，调整第二天的安排。

## 番茄工作法操作步骤
1. 选一件要做的事。
2. 设 25 分钟计时，这段时间只做这一件事。
3. 期间想到别的事，记在纸上，不去处理。
4. 计时结束，休息 5 分钟。
5. 每完成 4 个番茄钟，休息 15 到 30 分钟。
6. 记录每天完成了几个番茄钟，逐步了解自己的节奏。

## 输出模板
```
| 时间 | 时间块 | 内容 |
|---|---|---|
| 9:00-11:00 | 深度工作 | ……（4 个番茄钟） |
| 11:00-11:30 | 邮件消息 | |
| 14:00-15:00 | 会议 | |
今日完成番茄钟：……
```

## 常见误用
- 时间块排得太满，没有留缓冲，一出意外全乱了。
- 番茄钟期间还开着消息提醒。
- 把休息时间也用来刷手机，其实大脑没有休息。
