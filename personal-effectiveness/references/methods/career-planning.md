# 方法卡片：职业规划（剥洋葱法、职业规划六步、愿景与使命、领导梯队）

## 它解决什么问题
职业方向迷茫；或者正在转型（比如从业务骨干转成管理者），不知道该补什么。

## 怎么选
| 情况 | 用哪个 |
|---|---|
| 不知道长期想做什么 | 先想愿景与使命 |
| 有长期理想，但不知道当下该做什么 | 剥洋葱法 |
| 想做一份完整的职业规划 | 职业规划六步 |
| 从员工走向管理岗，或管理层级上升 | 领导梯队 |

## 什么时候不用
- 只是短期的工作安排问题：用目标或时间管理的方法。

## 愿景与使命
- 使命：我为什么想要？（关注“为什么”）
- 愿景：我想实现什么？（关注结果，而不是手段）
- 注意：不要把愿景和“比别人强”混为一谈。

## 剥洋葱法
从长期目标出发，一层层剥到今天：
10 年后想成为什么 → 5 年后需要达到什么 → 3 年后 → 1 年后 → 这个月 → 这一周 → 今天该做什么。

## 职业规划六步
1. 自我分析（可以用个人 SWOT、冰山模型）
2. 组织与社会环境分析
3. 评估职业机会
4. 确定职业目标
5. 制定行动方案
6. 评估与反馈，定期调整

## 领导梯队
管理自己 → 管理他人 → 管理经理 → 管理部门 → 管理事业部 → 集团高管 → 首席执行官。每上一级，需要的技能、时间分配和工作理念都要转变。最常见的问题是用上一级的方式做这一级的工作，比如当了经理还在亲自做业务。

## 输出模板
```
使命：……
愿景：……
剥洋葱：10 年 …… → 5 年 …… → 1 年 …… → 本月 …… → 今天 ……
当前所处梯队阶段：……；下一阶段需要的转变：……
```

## 常见误用
- 规划只停留在远期理想，没有剥到今天能做的事。
- 规划做一次就不再回顾。
