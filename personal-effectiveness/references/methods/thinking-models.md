# 方法卡片：思维模型（黄金圈、第一性原理、逆向思维、多元思维模型）

## 它解决什么问题
帮助自己看清事物的本质，或者从新的角度看问题，突破惯性思维。

## 什么时候用
| 情况 | 用哪个 |
|---|---|
| 做事只关注“做什么”，忘了“为什么” | 黄金圈 |
| 大家都照老办法做，想找根本性的突破 | 第一性原理 |
| 正向思考卡住了 | 逆向思维 |
| 想避免单一视角的偏见 | 多元思维模型 |

## 什么时候不用
- 这些更多是长期的思维训练，遇到需要马上执行的具体问题，还是要用具体的工具。

## 黄金圈
由内向外思考：
- Why（为什么）：目的、理念、信念
- How（怎么做）：方法、路径
- What（做什么）：具体的事情、结果
先想清楚为什么，再想怎么做和做什么；向别人说明时也按这个顺序，更有说服力。

## 第一性原理
1. 把问题拆到最基本的事实和原理，不接受“一直都是这样做的”。
2. 从这些基本事实出发，重新推导解决方案。
例子：电池太贵？不看市场价格，而是拆开看原材料成本是多少，再想怎么组合。

## 逆向思维
把问题反过来想：想成功，先想怎样一定会失败，然后避开；想增加客户，先想客户为什么会离开。

## 多元思维模型
从多个学科（心理学、经济学、物理学、生物学、历史等）借用思维模型看同一个问题，避免“手里拿着锤子，看什么都像钉子”。

## 输出模板
```
问题：……
为什么：……  怎么做：……  做什么：……
拆到最基本的事实：……
反过来想：怎样一定会失败？……
```

## 常见误用
- 把思维模型当口号，没有真正用在具体问题上。
- 第一性原理变成否定一切经验。
