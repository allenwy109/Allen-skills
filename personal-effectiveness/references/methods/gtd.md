# 方法卡片：GTD（尽管去做）与两分钟法则

## 它解决什么问题
事情来源多（邮件、消息、会议、临时交代），脑子里装着一堆没做完的事，总担心遗漏。GTD 把所有事情放到一个可信的系统里，让大脑专心做事。

## 什么时候用
- 事情多、来源杂，经常忘事。
- 已经有一定的自我管理基础，愿意花时间建立和维护一个系统。

## 什么时候不用
- 只想先轻量地试一试：用 1-3-5 法则。
- 事情很少、很单一：没必要用这么完整的系统。

## 五个步骤
1. **收集**：把所有要做的事、想法、承诺，都放进一个收集箱（笔记本、应用都可以），不留在脑子里。
2. **理清**：逐一处理收集箱里的每一项：
   - 不需要行动：删除、存档，或放进“将来也许”
   - 需要行动：两分钟内能完成的，马上做（两分钟法则）；不能的，委托给别人，或放进待办清单或日历
   - 需要多个步骤完成的，建成一个“项目”，并写下它的下一步行动
3. **组织**：按情境分类（在电脑前、打电话、外出办事），有具体时间的放进日历。
4. **回顾**：每周做一次回顾，清空收集箱，更新所有清单和项目。
5. **执行**：根据当前情境、可用时间、精力和优先级，选择下一件要做的事。

## 输出模板
```
收集箱：……
下一步行动（按情境）：
- 电脑：……
- 电话：……
项目及其下一步：……
等待别人：……
将来也许：……
```

## 常见误用
- 只做收集，不做每周回顾，系统很快就失效了。
- 项目只写了名字，没有写下一步具体行动。
- 花太多时间折腾工具，而不是做事。
