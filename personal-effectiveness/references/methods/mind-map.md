# 方法卡片：思维导图

## 它解决什么问题
把一个主题的相关要素发散出来、画在一张纸上，既能看到全局，又能看到要素之间的联系。

## 什么时候用
- 需要全面思考一件事，列出所有相关因素。
- 梳理一本书、一门课的结构。
- 头脑风暴时记录和整理想法。

## 什么时候不用，或换用什么
- 需要严格的逻辑结构来说服别人：用金字塔原理（见 consulting-analysis）。
- 一本 500 页的教材，每个细节都画成图，工作量太大。资料里特别提醒过这一点：只画主干和关键点就够了。

## 操作步骤
1. 在纸的中央写下主题。
2. 从主题出发画出几个主分支，每个分支是一个大类。
3. 在每个主分支上继续细分。
4. 每个节点只写关键词，不写句子。
5. 用颜色、图标区分不同的分支，用连线标出跨分支的联系。
6. 画完后回看：有没有遗漏？哪些分支最重要？

## 输出模板
```
主题：……
├─ 分支 1：……
│   ├─ ……
│   └─ ……
├─ 分支 2：……
└─ 分支 3：……
跨分支联系：……
重点：……
```

## 常见误用
- 把思维导图画成了一篇文章，节点上写满了句子。
- 追求画得漂亮，花大量时间在配图和颜色上。
- 只发散不收敛，画完没有结论。
