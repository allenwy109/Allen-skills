# 方法卡片：费曼技巧与学习金字塔

## 它解决什么问题
以为自己懂了，一讲就讲不清楚。通过“教别人”来检验和加深理解。

## 什么时候用
- 学习一个新概念、新理论、新知识领域。
- 准备给别人讲解或汇报之前。

## 什么时候不用，或换用什么
- 要提升的是技能（写作、演讲、编程），而不是理解：用刻意练习。
- 要记住大量事实（单词、公式）：用间隔重复。

## 学习金字塔
学习专家爱德加·戴尔提出，两周后还能记住的比例大致是：听讲 5%、阅读 10%、视听 20%、演示 30%、讨论 50%、实践 75%、教授给别人 90%。被动学习效果都在 30% 以下，主动学习在 50% 以上。这些数字常被引用，但并非严格的实验数据，更适合当作一个原则来理解：越主动，记得越牢。

## 费曼技巧四步
1. **选一个概念**，写在纸的最上方。
2. **讲给一个外行听**（或者假装讲给一个十二岁的孩子），用最简单的话，不用术语。
3. **发现卡住的地方**：讲不下去、只能用术语搪塞的地方，就是没真正懂的地方，回去重新学。
4. **简化和类比**：再讲一遍，直到能用简单的语言和生活中的类比讲清楚。

## 输出模板
```
概念：……
我的简单解释：……
卡住的地方：……
补学后的解释：……
一个类比：……
```

## 常见误用
- 只在脑子里默讲，没有写下来或说出来，发现不了漏洞。
- 讲的时候偷偷用术语掩盖不懂的地方。
