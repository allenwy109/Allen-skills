# 方法卡片：4P / 7P 营销组合

## 它解决什么问题
诊断或设计营销策略：产品、价格、渠道、推广四个方面是否协调、是否对准目标客户。服务业再加人员、流程、有形展示，扩展为 7P。

## 什么时候用
- 销售不及预期，想检查营销组合哪里出了问题。
- 新产品上市，设计营销方案。

## 什么时候换用别的
- 还没想清楚卖给谁：先做客户细分和 STP。
- 问题是行业整体萎缩：先看 PEST 或五力。

## 前提与不能推出什么

**前提（缺了就先补信息或换方法）**
- 已经明确目标客户和定位（STP 已做或已知）
- 能拿到产品、价格、渠道、推广的现状数据或至少可靠描述

**不能推出什么**
- 4P 诊断出“哪里不一致”，不能直接证明改了就能提升销量
- 不能推出行业整体前景

## 操作步骤
1. 先写明目标客户和定位（来自 STP）。
2. 逐项检查：
   - 产品：功能、质量、品类、包装、服务是否满足目标客户的需要
   - 价格：定价水平、折扣、付款方式是否与定位一致
   - 渠道：客户在哪里买、渠道覆盖和效率如何
   - 推广：广告、促销、公关、销售团队是否触达目标客户
   - （服务业）人员、流程、有形展示
3. 检查四个 P 之间是否一致：高端定位却在折扣渠道卖，就是不一致。
4. 找出最薄弱的一两个 P，提出改进。

## 输出模板
```
目标客户与定位：……
| 要素 | 现状 | 与定位是否一致 | 问题 | 改进建议 |
|---|---|---|---|---|
| 产品 | | | | |
| 价格 | | | | |
| 渠道 | | | | |
| 推广 | | | | |
```

## 常见误用
- 四个 P 各自为政，不看相互是否一致。资料里的提醒是：避免陷入“低价格一定有好营销”的误区。
- 没有先定目标客户就开始谈 4P。
